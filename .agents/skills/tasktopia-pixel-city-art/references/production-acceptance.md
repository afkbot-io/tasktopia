# Compact building-source acceptance

Read `docs/art/COMPACT-BUILDING-ART-CONTRACT.md`, family `geometry.json` and
the generator/verifier skills. These are the current building authority.
The reviewed catalog and `COMPACT_BUILDING_SHAPES` define current compact
envelopes, including separately authored long and court forms. Old category
quotas and large building benchmarks do not authorize restoring retired assets.

## Before generation

1. Define semantic role, actual slot footprint, anchor and entrance before art.
2. Inspect the family's approved stage5 source and contracted native pixels.
3. Pin roof/facade/floor/door/window measurements in geometry.
4. Generate stage5 first, then4, then3 independently with stage5 as authority.
5. Preserve common source frame and aspect ratio; reject perspective/scale
   errors instead of stretching or procedurally replacing the architecture.

## Before publishing

- Register exactly three independent AI source PNGs, geometry, report and review
  beneath `reference/ai-authored/<family-key>/`.
- Retained rejected attempts are provenance only, never catalog sources or
  published files. Add a new physical envelope only after four-corner packing,
  connected entrance, clearance and fixed-stage-parcel tests pass. Keep the
  historical V2 vocabulary and stored V3 parcels immutable.
- Stages0–2 are slot/shared-kit composition. Never register generated sources
  for those stages or bake external fence/ground into stage3–5.
- Run `npm run assets:compact:verify` and independently inspect each stage at
  native scale and nearest-neighbour zoom. The structural mask, not just the
  overall bounding box, must remain registered.
- Record current source/runtime hashes, dimensions, camera/roof/wall semantics
  and stage identity in `visual-review.json`. Never auto-approve a new source.
- Publish with `npm run assets:build`; it verifies review before copying exact
  accepted normalized stage3–5 bytes and regenerates only the compact kit.
- After the builder completes, run `npm run assets:verify`. Terrain, tree,
  vehicle and other ambient audits remain blocking.
- Review actual map placement and five-stage progression. Catalog thumbnails
  for stages1–2 do not substitute for checking runtime fence, crane, cabin,
  gate, sidewalk and neighbouring-slot composition.

Reject interior transparency, inconsistent camera, moved doorway, invisible
construction progression or unreadable native clusters even if hashes pass.
Stage3 assembly is not an image-height ratio. A roofless structure retains
the complete projected interior and physical lot.

Never publish a comparison sheet as a building source. It is evidence only.
