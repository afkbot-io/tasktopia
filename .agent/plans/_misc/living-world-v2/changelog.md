# Release notes draft

## Added

- Перегенерация пространственной проекции страны без потери задач и истории.
- Экранные события с редким пиксельным самолётом.
- UI удаления города, района и задачи.

## Changed

- Агенты сохраняют состояние при загрузке чанков и получают новые позиции после reload.
- Машины и пешеходы следуют маршрутам по графу.
- Лодки/рыбаки реже и имеют дешёвую idle-анимацию.
- Парки и уличный декор публикуются стабильнее.
