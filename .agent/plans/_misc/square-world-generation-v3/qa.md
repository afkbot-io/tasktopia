# Square World Generation V3 — QA

## 1. Unit и property-тесты

### Координаты и чанки

- `world→chunk/local→world` для диапазона `[-100000, 100000]`.
- Соседние клетки на каждой границе чанка.
- Отрицательные координаты и `floorMod`.
- Взаимность road mask: `E` одной клетки означает `W` соседней.

### Детерминизм

- Одинаковые seed, generatorVersion и command log дают одинаковый hash мира.
- Перестановка порядка запросов чанков не меняет snapshot hash.
- Добавление задачи в район A не меняет hash района B.
- Повтор идемпотентной команды не создаёт вторую сущность.

### Природа

- У river feature нет разрывов внутри региона и на shared edge.
- Озеро является связной компонентой и не содержит запрещённых одноклеточных выбросов.
- Береговая маска согласована с водой.
- Лес не занимает дорогу, committed building или глубокую воду.

### Города и дороги

- City envelopes и growth reserves не пересекаются сверх разрешённого коридора.
- Все города входят в одну компоненту национального road graph.
- Каждый road edge растеризован непрерывно.
- Весь road profile, а не только centerline, проходит clearance-проверку; junction является связным объединением профилей.
- Мост имеет два берега, прямой пролёт и не содержит junction.
- Ни одна национальная дорога не пересекает protected feature без разрешённого crossing.

### Районы

- Граница района связна, без дыр и одноклеточных tendrils.
- Районы не перекрываются.
- Growth sectors двух активных районов не перекрываются.
- `SEALED` район сохраняет hash после всех следующих операций.
- Expansion меняет только `RESERVED/NATURAL` клетки допустимого сектора.
- Gross/buildable budgets считаются отдельно и сходятся с фактическими клетками.

### Задачи

- Footprint соответствует manifest и rotation.
- Здание целиком внутри района/расширения, не пересекает воду и occupancy.
- Есть путь от входа участка до дорожной/пешеходной сети.
- При невозможности размещения возвращается объяснимый `PLACEMENT_BLOCKED`.
- Стадия меняется без изменения anchor/footprint.

## 3. Нагрузочные сценарии

### S1. Открытие страны

Первый город, viewport 160×100 cells, prefetch ring. Измеряются TTFB snapshot, generation time, payload gzip и память браузера.

### S2. Десять городов

`10 cities × 8 districts × 25 tasks`; последовательный pan через страну и выбор каждого города. Проверяются FPS, число resident chunks, cache hit rate и WebSocket payload.

### S3. Burst MCP

50 `AddTask` в один активный район и 20 в соседний. Проверяются блокировки, повторы jobs, корректность revision и отсутствие двойного occupancy.

### S4. Расширение

Район заполняется footprints от маленьких к крупным и наоборот. Сравниваются успешность, добавленная длина дорог, площадь расширения и churn reserved cells.

## 4. Целевые бюджеты для первого профиля

- cached chunk P95 ≤ 50 ms;
- new base chunk P95 ≤ 250 ms;
- district planning P95 ≤ 500 ms для 32 кандидатов;
- city + national connection job P95 ≤ 3 s;
- WebSocket event ≤ 16 KB обычно; большой результат передаётся invalidation + HTTP snapshot;
- клиент ≤ 200 resident chunks и ≥ 50 FPS на целевой машине.

Значения являются начальными SLO и должны быть подтверждены бенчмарком, а не объявлены достигнутыми заранее.

## 5. Визуальный QA

- Нет жёлтых/случайных линий между 8×8 плитками.
- Материалы имеют одну палитру и одинаковый размер пикселя.
- Районы различимы мягкой UI-обводкой, но город не превращается в цветную мозаику.
- Дороги имеют осмысленные T/L/loop формы и не заканчиваются у здания без cul-de-sac/площадки.
- У платформ зданий есть целостный asphalt/paving/yard boundary.
- Реки меандрируют, озёра имеют разные формы, мосты читаются как мосты.
- Декор не закрывает входы и не создаёт визуальную коллизию со зданиями.

## 6. Регрессия итерации 0.4

- На чистом seed открыть первый город: нет полного дорожного креста через `100×100`, въезд заканчивается компактным городским узлом.
- Создать три района разной ёмкости: каждый имеет локальную main street и ветви, улицы не уходят к посторонним трассам.
- На минимальном zoom перетащить карту к четырём границам: renderer background не виден, камера дальше не движется.
- Быстро протянуть карту больше чем на пол-экрана: следующий prefetch ring появляется до отпускания указателя.
- Сравнить два seed: формы леса, озёр и гор различаются, но повтор одного seed даёт одинаковый screenshot/state hash.
- Проверить desktop `1440×900`, mobile portrait `390×844`, отсутствие console errors и resident chunk budget менее 200.
