## Оставшиеся неблокирующие ограничения

- Production bundle содержит основной JS chunk `510.76 kB` и выдаёт предупреждение Vite. Для MVP допустимо; следующий performance slice — lazy loading Pixi/панелей.
- SQLite остаётся режимом одного экземпляра. Для горизонтального масштабирования по-прежнему нужны PostgreSQL и общий event broker.
- Рендер использует per-cell sprites. Сценарий 10/80/250 проходит бюджет, но нагрузка существенно больших стран должна проверяться отдельным длительным browser soak.
