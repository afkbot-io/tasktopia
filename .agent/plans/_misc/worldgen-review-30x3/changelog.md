# Changelog

## Unreleased

### Added

- Воспроизводимый плотный demo/review fixture: три города, три района и 30 задач на город.
- Пространственный и performance audit этого сценария.
- Soak-проверка того же сценария на десяти независимых seed.
- Проверка всех пяти стадий и разнообразия зданий по каждому городу.

### Changed

- Генератор повышен до `square-v5`: highway входит через внешний portal, а не прокладывает произвольный путь внутри city bounds.
- Позиция здания выбирается только среди footprint с доступом к дороге не дальше двух клеток.
- Камера фокусируется на фактически занятых районах разросшегося города.
- Chunk API получил независимый лимит 600 запросов в минуту и больше не расходует бюджет интерактивного API.

### Fixed

- Боковые клетки широкой дороги больше не пересекают уже опубликованные здания.
- После обхода препятствия не остаются изолированные дорожные острова.
- Ошибки middleware с HTTP-статусом, включая rate limit `429`, больше не превращаются в `500`.
- Метрика дорожных развилок схлопывает широкие перекрёстки в топологические зоны вместо подсчёта сотен внутренних клеток.
