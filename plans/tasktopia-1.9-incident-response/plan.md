# Tasktopia 1.9 — дефекты и визуальный incident response

## Решение

Родительская задача в `TESTING` не откатывает строительную стадию из-за каждого найденного дефекта. Связанный дефект имеет собственный проверяемый жизненный цикл, а задача не может перейти в `COMPLETED`, пока остаётся хотя бы один не исправленный дефект.

## State machine дефекта

| Состояние | Смысл | Следующие состояния |
| --- | --- | --- |
| `OPEN` | дефект воспроизведён и ожидает работы | `IN_PROGRESS`, `FIXED` для тривиального исправления |
| `IN_PROGRESS` | исправление выполняется | `VERIFYING` |
| `VERIFYING` | исправление готово и повторно проверяется | `FIXED`, `IN_PROGRESS` при неудачной проверке |
| `FIXED` | ожидаемый результат подтверждён | `OPEN` при повторном обнаружении |

Повтор того же состояния разрешён для уточнения доказательств. Переход задачи `TESTING → IN_PROGRESS` остаётся только для существенной переработки самой задачи, а не для обычного связанного дефекта.

## Визуальные состояния

| Условие | Карта |
| --- | --- |
| `OPEN` defect | пожарная машина с сигнальным маяком у здания |
| `IN_PROGRESS` defect | машина и прерывистая струя к небольшому очагу |
| `VERIFYING` defect | машина, затухающий дым, без активного огня |
| активная задача `HOTFIX` | усиленный огонь, дым, машина и струя |
| всё исправлено / задача завершена | incident overlay отсутствует |

Incident overlay создаётся только для задач видимых detail-чанков, не хранится как геометрия, не участвует в collision/pathfinding и использует не больше одного контейнера на здание. Анимация меняет только transform/visibility/alpha уже созданных объектов и отключается при `prefers-reduced-motion`.

## Acceptance criteria

- Дефект проходит собственные состояния без изменения статуса и процента родительской задачи.
- `COMPLETED` отклоняется при любом дефекте не в `FIXED`.
- Chunk detail содержит компактную сводку дефектов; overview не загружает incident sprites.
- `HOTFIX` и дефекты имеют различимые, но согласованные визуальные режимы.
- Все новые PNG соответствуют сетке 8 px, hard-alpha и существующей палитре.
- MCP, публичный `ai.md` и Tasktopia skill описывают переходы и completion guard.
- Малый тестовый контур, asset audit, build и map E2E проходят без регрессий.
