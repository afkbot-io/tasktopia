# Исправления интерфейса и карты после PR #45

Продолжение [задачи №43](https://tasktopia.online/task/43?countryId=4201d605-751a-469b-8d5f-a7e322a7ece1&taskId=f59e7e3b-f558-47a3-9cd3-a4a5863f2d58), база `7ff26f20`, ветка `codex/planet-ui-feedback`. Пользователь передал девять замечаний и поручил реализацию. Эта доработка не выложена на сервер.

## Результат

1. Нижняя панель занимает ширину трёх кнопок, без оставшейся четвёртой колонки. На телефоне нет растяжения на весь экран.
2. На планете панели нет. Вход в город — через его миниатюру/подпись, Enter или дальнейшее приближение. В городе доступны возврат на планету и районный слой.
3. Размер миниатюр привязан к канонической географической клетке и ограничен расстоянием до соседей. Центры городов и блоков, фактическая застройка и транспортные якоря не меняются. Соседи ищутся в пространственных корзинах; размеры не пересчитываются при движении камеры.
4. Zoom <1,25 — без подписей; 1,25–2,6 — названия стран; ≥2,6 — названия городов. COUNTRY не возвращается как режим. На узком экране размер подписей компенсирует масштаб SVG.
5. Ландшафт собирается один раз на ревизию атласа из тех же четырёх material patches на клетку. Небольшие PNG-кэши покрывают не более 16×16 макроклеток; пиксели сохраняются без сглаживания. Камера меняет матрицу слоя. Вне экрана страны не рисуются; ненужные строки маски и край планеты не попадают в DOM. Ошибка/таймаут подготовки показывают прежний экран с повтором, отменённый запрос не публикует старую ревизию.
6. Координаты облаков, размер, скорость и фаза получают независимые seeded-каналы вместо связанных XOR-значений. Облака не переставляются на каждом кадре и сохраняются при повторном открытии.
7. Сводка открывается по колокольчику в шапке; число событий — небольшой индикатор. Курсор прочтения по-прежнему обновляется только после показа содержимого. Кнопка профиля использует размеры, рамку и фон остальных кнопок, статус находится внутри.
8. Меню, настройки, обозначения и уведомления закрывают предыдущую панель мышью и клавиатурой. Работают внешний клик и Escape с возвратом фокуса. Вложенные мобильные настройки сохраняют родительское меню. Открытие верхнего инструмента также закрывает список городов/районов и выбор мира.
9. Фильтр доступен только в открытом CITY. При возврате на планету он исчезает.

## Производительность

Локальный production-клиент, Chromium, 1440×900, DPR2, CPU×4. Фикстура: шесть стран из одной локальной тестовой страны, увеличенная насыщенность, без записи в БД. Камера 5,47; три прохода по 2,5 секунды с движением влево/вправо. Цель: p95 кадра ≤50 мс и отсутствие пауз >200 мс после прогрева. Это лабораторный сценарий, а не гарантия для любого устройства.

Небольшие исходные terrain sheets для canvas берутся с того же versioned-пути на origin приложения. Это избегает tainted canvas из ранее закэшированного display-only ответа CDN без CORS. Облака и океан сохраняют обычный путь доставки. PNG-кэши живут только в памяти клиента и не меняют публичный пак.

## Приёмка

- `typecheck`, `lint`, production build и адресные unit-проверки геометрии/подписей/облаков/навигации/курcора сводки.
- Playwright: переключение подписей, отсутствие панели и фильтра на планете, точная ширина панели на 1440 и 390 px, взаимоисключение верхних окон, повтор после ошибки графики и данных, прямой вход/возврат, отмена входа, транспорт, уведомления и mobile settings. Камера не заменяет DOM кэшированного ландшафта при зуме.
- Native screenshot: дальняя планета, подписи стран и городов, телефон с уведомлениями, городской переключатель.
- Для проверки вручную: открыть планету, последовательно приблизить страну и город; проверить маленькие дома и отсутствие скачка географии. Войти в город, включить районы/фильтр, вернуться. Открыть настройки, обозначения, меню, уведомления по очереди; проверить Escape и клавиатуру. На телефоне проверить ширину панели и читаемость названий.

Миграций, изменений прав, API/DTO, ассетов на диске и серверной генерации нет. Данные не перегенерируются. Откат — предыдущая версия клиентского кода. Полная матрица симуляции, генерация островов и release/recovery-проверки локально не повторяются: соответствующие границы не менялись. Точные результаты приёмки и ревизия указываются в итоговом отчёте задачи/PR.

## Доказательства проверки

Node 24.15.0: typecheck, lint, production build; 33 unit-теста в восьми файлах. Финальные адресные браузерные прогоны: 21/21 для геометрии, навигации и CDN; 21/21 для повторов загрузки, настроек и интерфейса в Chromium/WebKit (наборы частично пересекаются). Ранее отдельно прошли сценарии уведомлений и курсора прочтения. AI-ревью итогового diff не выявило блокирующих замечаний.

На высоком экране оптимизация маски первоначально обрезала океан прямой линией. Расчёт исправлен с учётом видимой области SVG вне номинального viewBox; регрессия воспроизведена тестом и проверена в обоих движках.
