# QA 1.6 — живые агенты, удаления и перегенерация

## Автоматические проверки

```bash
npm run test:db:start
npm run typecheck
npm run lint
npm test
npm run assets:verify
DATABASE_URL=postgres://tasktopia:tasktopia@127.0.0.1:55432/tasktopia_test npm run test:e2e
```

Обычный набор использует малый мир. Ресурсный `npm run test:scale` запускается отдельно и не должен идти параллельно с unit/E2E.

## Карта и движение

1. Открыть detail-карту, запомнить несколько машин и людей, приблизить и отдалить карту без перехода в overview, затем немного сдвинуть viewport. Видимые агенты продолжают движение с текущей позиции; синхронного перезапуска анимаций нет.
2. Перезагрузить страницу. `data-agent-session` меняется, а жители начинают в других клетках.
3. На длинной дороге машина едет до следующего выбранного узла. На перекрёстках маршруты различаются; разворот в середине продолжающегося участка не происходит.
4. Машина ждёт занятую пешеходом зебру. Люди используют тротуары, короткие безопасные соединения и делают паузы около лавок, парков, площадок и остановок.
5. Лодки и рыбаки встречаются редко и слегка анимированы. Самолёт иногда проходит слева направо над всеми слоями, не меняя масштаб при zoom. В reduced-motion эти анимации отсутствуют.

## Удаления

1. В плане удалить задачу с точным подтверждением. Здание исчезает после realtime-инвалидации, lot становится свободным, соседняя геометрия не меняется.
2. Удалить район. Его задачи, парк и дочерний декор исчезают; если район был активным, активируется следующий плановый.
3. Удалить город. Его районы, задачи и локальные дороги исчезают, а национальная сквозная highway остаётся связной.
4. Неверное подтверждение отклоняется. Наблюдатель не видит кнопок и получает `403` при прямом запросе.

## Перегенерация

1. Создать один город, несколько районов и задач. Изменить статусы, назначить ответственного, добавить комментарии.
2. В управлении страной нажать «Перегенерировать мир» и ввести точное название страны.
3. Во время операции кнопка блокируется. После завершения меняются рельеф, размещение, дороги и окружение.
4. Сверить исходные ID, названия, статусы, прогресс, оценки, сроки, ответственных, комментарии и хронику — они не изменились.
5. При искусственной ошибке генерации исходный seed и вся старая геометрия должны сохраниться; временной страны в БД нет.
