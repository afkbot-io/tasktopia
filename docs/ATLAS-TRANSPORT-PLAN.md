# Согласование масштабов и обзорный транспорт

Продолжение прямого запроса пользователя. Сохраняем простые микроспрайты, меняем только резкость и согласованность отображения.

1. Уменьшить таблички планеты и сблизить шрифт/палитру/плотность со страной. Проверка: сравнительные снимки трёх масштабов и мобильного экрана.
2. Передавать только завершённые вокзалы из активных размещений. Добавочное необязательное поле `stations`; прежние DTO без него читаются как отсутствие ЖД. Ревизия планеты включает инфраструктуру, поэтому старые обзорные снимки инвалидируются без миграции таблиц.
3. Строить обзорные ЖД-связи между городами с вокзалами по связной сухопутной сетке. На планете запрещены пути между континентами; на стране — пересечения воды. Это картографический слой, не изменение симуляции городского транспорта. Проверки: маршруты по суше, отсутствие при незавершённых вокзалах, согласованность API.
4. Добавить немного очень маленьких кораблей между берегами разных континентов. Путь строится только по морским ячейкам, без движения через сушу. Не требуется выдумывать задачи портов.
5. Проверить полёты между завершёнными аэропортами и видимость самолётов. Без пары аэропортов фиктивных рейсов не добавлять. Не сглаживать спрайты при смене направления.
6. Затронутые модульные/API-проверки, сборка, линтер и локальный браузерный сценарий с транспортом. Внешние страны не изменять; релиз не входит в запрос.

## Результат и проверка

Таблички планеты уменьшены с 132×34 до 84×20 единиц SVG: площадь меньше примерно на 63%. Остались название и тонкий индикатор прогресса, полное описание доступно через SVG title и aria-label. Палитра согласована со страной. При входе планета показывает общий обзор, а текущая страна выделяется. Размер пикселя воды вне растрового участка страны согласован с основной картой.

`stations` содержит завершённые вокзалы из активного размещения. Отсутствующее поле означает пустой список. Строящиеся и недоступные пользователю объекты исключаются. ЖД строится как обзорная сеть по сухопутным ячейкам: город соединяется с обслуживаемым городом в той же связной области. Это картографическое отображение, не сохранённая инженерная трасса и не симуляция поездов.

Маленькие корабли ходят туда и обратно только по воде между берегами разных континентов. В стране самолёты используют четыре готовых направления и целые экранные координаты; рейсу по-прежнему нужна пара завершённых аэропортов.

29 модульных и HTTP-проверок затронутой области прошли. Проверены авторизация API, исключение чужих стран, смена ревизии при появлении вокзала и отсутствие строящегося вокзала в ответе. Линтер, TypeScript и сборка прошли. Два браузерных сценария прошли в Chromium: прежние 16 исправлений и новый транспорт; проверяется изменение координат самолёта и корабля, настольный и мобильный размеры окна.

Сравнительные снимки находятся в `screenshots/atlas-transport`. Транспортный браузерный сценарий использует явно заданные обзорные DTO для четырёх стран и двух городов. Это проверка отрисовки, не реальные данные Дедлайново. Источник инфраструктуры отдельно проверен через HTTP и тестовую БД. Ревью выполнено основным агентом. Продакшен не изменён; миграций таблиц нет.


## Исправление масштаба и чёткости после 1.24.4

Страна сохраняет один исходный растровый слой, но отображает его через canvas размера viewport с учётом DPR (до 2). `imageSmoothingEnabled=false` применяется при каждом рисовании; CSS больше не уменьшает и не увеличивает растр. География и серверные снимки прежние.

Здания страны рисуются из исходных изображений в конечном размере, повторное рисование происходит только при изменении зума. Дома, внутренние расстояния, подписи, области перехода и станции используют согласованный масштаб. На планете дома и аэропорты также растут пропорционально зуму. Страна представляет занятые кварталы, планета — районы; оба режима используют существующий каталог зданий с сохранением пропорций.

Корабли увеличены с 6×2 до 18×6 при базовом масштабе, увеличиваются вместе с картой. Цикл движения замедлен до 90+11×индекс секунд; повороты ограниченно скругляются внутри ближайших участков морского маршрута.

Проверки: 30 целевых unit-тестов; шесть браузерных сценариев Chromium/WebKit (навигация, масштаб, транспорт, 150 городов), отдельный Chromium DPR=2 при зуме >2.5. Максимум кадра перемещения в фикстуре 150 городов: Chromium 2.6 мс, WebKit 3 мс. Это измерение локальной камеры, не всей загрузки игры. Скриншоты — `screenshots/atlas-transport`, крупный план — `country-close-retina.png`.

Дефект задачи 16: `01b74e23-e5ed-4b92-a538-72c8ad1f5d08`. Проверка выполнялась на локальной тестовой БД и обзорных DTO, без изменения данных продакшена. Релиз этого исправления отдельно не выполнялся. Откат — возврат клиентского коммита; миграций и пересборки мира не требуется.
