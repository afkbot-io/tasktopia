# Паттерны README для open-source Tasktopia

Дата проверки: 10 августа 2026 года.

## Первичные источники

- [Plane](https://github.com/makeplane/plane) начинает с короткого product
  promise, показывает продукт и сразу разделяет cloud и self-host installation.
- [OpenHands](https://github.com/OpenHands/OpenHands) сначала объясняет семейство
  продукта и сценарии использования, затем ведёт к конкретному quick start.
- [OpenClaw](https://github.com/openclaw/openclaw) использует характерный голос,
  сильную метафору и короткое определение продукта до технических деталей.
- [Hermes Agent](https://github.com/NousResearch/hermes-agent) даёт проверяемую
  установку, отдельный contributor flow и явно показывает MIT license.

## Применённые решения

1. Первый экран Tasktopia отвечает на четыре вопроса: что это, для кого, чем
   отличается и где попробовать.
2. Метафора страны вынесена в короткое «обращение главы государства», но сразу
   после него дана строгая таблица соответствия сущностей задачника.
3. Вместо галереи концептов используется один большой скриншот настоящего
   воспроизводимого мира.
4. Возможности разделены по пользовательской ценности: управление работой,
   живой мир, MCP и realtime.
5. Docker quick start остаётся коротким; nginx, TLS, backup и update вынесены в
   отдельную эксплуатационную документацию и автоматизированный installer.
6. Количественные заявления берутся из versioned manifest или кода MCP.
7. License, contribution и security доступны из корневого каталога, как у
   зрелого open-source проекта.

Тексты источников не копировались; использована только структура подачи и
проверяемые документационные паттерны.
