# Карточка, навигация и альбом города

Дополняет план задачи53 и наблюдение городского мира. Интерфейс продолжает выбранный Forest Atlas из `public/forest-theme.css`; новую тему и набор шрифтов не вводим.

## Основа

Палитра: фон `#0b1814`, панель `#10251d`, поднятый контрол `#172f26`, граница `#365647`, текст `#f0f2e7`, акцент действия/фокуса `#d9bd78`. Manrope остаётся общим локальным шрифтом. Заголовок альбома24px, вехи18px, основной текст14px, дата12px. Даты служат ориентиром реальной хронологии; декоративную нумерацию и постоянные подписи над объектами не добавляем.

Альбом — одно окно с последовательностью реальных вех. Для каждой вехи видны дата, факт, ссылка на существующую задачу и изменившиеся фактические показатели в таблице «До / После». В старой истории без снимка остаются дата и факт. Удалённый объект имеет подпись и не открывает сломанную ссылку. Не превращаем числа в валюту, награду или выдуманный прогресс.

```text
Альбом города                             закрыть
Название города
------------------------------------------------
Дата
Факт развития
Существующая задача
Показатель                          До     После
------------------------------------------------
Назад                  Страница N          Далее
```

Выравнивание по левому краю, окно до620px, поля24px/16px на телефоне, вертикальный ритм6/10/16/20px. Кнопки минимум44px; на320px все три колонки и пагинация укладываются в окно. Используем текущие роли цветов, границ, радиусов и тени. Хронология, компактная таблица и реальные названия относятся к жизни этого города; повторяющиеся маркетинговые карточки и крупные декоративные счётчики здесь не нужны.

## Поведение

- Карточка сначала читает компактный паспорт. Обсуждение, история и остальные коллекции читаются страницами50; Markdown документа — только после выбора. Ошибка страницы имеет повтор, права доступа очищают тело, поздний ответ после ухода не возвращает окно.
- История браузера принадлежит приложению. Карточка не переписывает URL при каждом обновлении данных и не удаляет его при размонтировании. Ссылка содержит countryId и канонический UUID, номер служит человеку. Back/Forward восстанавливают задачу/город и сохранённую камеру; изменение камеры обновляет текущую запись без новых записей на каждый кадр.
- Зависимость является обычной ссылкой. Обычное нажатие открывает связанную карточку в приложении, модификатор/новая вкладка сохраняют браузерное поведение. Хроника показывает только разрешённые небольшие прежние/новые значения; имя исполнителя берётся из реального снимка, внутренний UUID не показывается.
- Альбом загружается отдельно при открытии, максимум20вех на странице, ограниченное ожидание15s, повтор и очищение при уходе. Он не задерживает первый кадр города.
- Фокус удерживается общим владельцем диалогов; Escape/закрытие возвращают управление. Reduced motion сохраняется, декоративной автономной анимации альбом не требует.

## Приёмка дизайна

Проверить нативные снимки desktop1440×900/1440×1100 и320/390/393px, длинные названия, нулевые/старые вехи, удалённую задачу, страницу20/50элементов, отказ/повтор, восстановление фокуса и камеру Back/Forward. Axe, типизация и линтер дополняют просмотр изображений. Проверка в физическом телефоне не заявляется: пользователь выбрал браузерную эмуляцию Android/iPhone.
