# Навигация при смене сессии и отмене восстановления

16.10.2026, локальный Vite5315 с fresh QA200 API5316. App оставался
неизменным во время серии; тесты не редактируют код приложения и не создают
задачи, события, страны или участников.

## P1 — запоздалый выбор страны из начальной ссылки

Начальная ссылка содержит другой countryId. Ответ select удерживается,
пользователь выполняет настоящий выход через настройки и настоящий вход
через форму. Затем возвращается старый ответ. Страница сохраняет текущий
мир и действующую сессию; старое название и scope не появляются.

Ответ выбора другой страны контролируется HTTP-перехватом и получен из
реального авторизованного bootstrap с отличающимся scope. Это проверка
клиентского auth epoch/generation/request fence, а не доказательство реального
доступа пользователя к другой стране. Регистрация/изменение membership не
выполнялись. Серверные logout/login вернули HTTP200, `/api/bootstrap`
подтвердил исходного пользователя и страну после запоздалого ответа.

## P2 — явная PLANET отменяет запоздалое CITY восстановление

Реальный город открыт, выбрана задача. Через существующее WebSocket
соединение контролируемо передаётся Socket.IO frame, инвалидирующий кеш
сцены; это не запись события в серверную БД. Новый scene HTTP удерживается.
Browser Back закрывает задачу и начинает CITY popstate restore; пользователь
нажимает видимую кнопку «Планета». Затем реальный backend scene ответ
доставляется через route.fetch/fulfill. После подтверждённой доставки старого
ответа карта остаётся PLANET, карточек нет, URL не содержит cityId.

Chromium и iPhone WebKit: **4/4 PASS** (16.5s). После усиления проверки
именно поздней доставки scene P2 повторён: **2/2 PASS** (10.3s).
Оба конечных history.state имеют view.mode=PLANET и taskDepth=0.
JavaScript pageerror отсутствовали. Проверки после исправлений root;
предыдущее поведение этой серией не выполнялось и RED не заявляется.

ESLint и отдельная strict TypeScript граница нового сценария прошли.
Это функциональная проверка с Vite и браузерной эмуляцией, не performance
benchmark/испытание физического устройства. Общая immutable CI/release
квалификация выполняется отдельным этапом.
