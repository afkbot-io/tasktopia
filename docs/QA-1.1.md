# QA релиза 1.1

## Автоматические проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
DATABASE_URL=postgres://tasktopia:tasktopia@127.0.0.1:55432/tasktopia_test npm run test:e2e
```

Основной набор использует один тестовый город, 10 районов и 20 задач. Отдельный `npm run test:scale` не запускается одновременно с unit/E2E и предназначен только для проверки ресурсных бюджетов.

## Регистрация

1. Переключиться на регистрацию и проверить краткую схему «страна → город → район → здание».
2. Заполнить имя, email, пароль, название первой страны и города.
3. После отправки должна открыться карта: верхняя панель показывает введённые названия страны и города.
4. Ошибка генерации должна откатить пользователя, страну, сессию и город целиком.

## Страны и правительство

1. Открыть название страны в верхней панели.
2. Глава страны видит формы переименования, создания страны и приглашения участника.
3. После переименования окно закрывается, а новое название появляется в верхней панели.
4. Министр и наблюдатель не видят форму переименования; прямой PATCH возвращает `403`.
5. На ширинах 375, 768 и 1440 px нет горизонтальной прокрутки. На mobile окно занимает viewport и прокручивает только содержимое.
6. Escape закрывает окно, Tab не покидает диалог, после закрытия фокус возвращается к кнопке страны.

## Карта и регрессии

1. Перетаскивание, zoom, overview/detail LOD и лимит resident chunks работают как в 1.0.
2. Переключатели плана и районов доступны на desktop и mobile.
3. MCP endpoint остаётся `/mcp`, а токены передаются только через `Authorization: Bearer`.
