# Pixel City Asset Storybook

Storybook — отдельная read-only QA-страница для проверки всего игрового пака без
создания тестового мира. Она читает текущий `manifest.json`, поэтому новые и
удалённые runtime-ассеты появляются в ней после повторной сборки одной командой:

```bash
npm run assets:storybook
```

Результат: `screenshots/pixel-city-storybook/index.html`.

## Режимы

- `?variant=A` — большой город: каждое семейство идёт отдельным участком со
  стадиями 1 → 5, а категории образуют районы.
- `?variant=B` — компактный каталог с поиском по названию, ключу и тегам.
- `?variant=C` — строгая таблица геометрии: пять стадий на общей плиточной
  сетке для поиска смещения центра, baseline и неверного масштаба.

Стадии 1–2 помечены как `runtime-конструктор`: это не старые индивидуальные
фасады, а базовый слой параметрической стройплощадки. В игре поверх него
детерминированно размещаются грунт, фундамент, ограждение, техника и детали
по footprint задачи. Индивидуальными AI-authored изображениями являются
стадии 3–5.

Ниже зданий расположены отдельные секции для пяти стадий парков, четырёх
направлений транспорта, жителей, деревьев, уличных объектов, спецэффектов,
всех 12 terrain families и инфраструктурных материалов `8×8`. Для каждого
authored prop выводится его V5 visual profile; появление активного V4-профиля
останавливает проверку.

Городской транспорт использует `city-train-v3` и `city-ferry-v1`: восемь частей
локомотива/вагона и четыре парома, самостоятельно нарисованные для E/N/W/S.
Canvas — 24×24 px, anchor — 12,12; допустимы только целые пиксели,
nearest-neighbour, hard alpha и восемь цветов. Поворот или зеркалирование PNG
не заменяют отдельное направление. `scripts/city_transport_contract.py`
проверяет source rectangles, SHA каждого исходника и runtime PNG, палитру и
границы непрозрачного корпуса. Visual review хранится рядом с исходниками;
storybook дополняет проверку в реальном городе и не доказывает корректность
посадки, мостов или столкновений.

## Проверки

Перед записью HTML генератор проверяет наличие каждого PNG, ровно пять стадий
для каждого здания, совпадение фактического canvas с размером manifest и
отсутствие устаревших visual profiles.
Storybook не растягивает исходники: масштаб `1×/2×/3×/4×` всегда целочисленный
nearest-neighbour. Для автоматического gate используется:

```bash
python3 scripts/render-pixel-city-storybook.py --check
npm test -- --run tests/pixel-city-storybook.test.ts
```
