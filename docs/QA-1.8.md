# QA Tasktopia 1.8.0

## Автоматический контур

- `npm run lint` и `npm run typecheck` — контракты React, Fastify, MCP и Pixi.
- `npm test` — миграция `0004`, сохранение AI-полей и дефектов при перегенерации, доменные инварианты и документация.
- `npm run assets:verify` — manifest, размеры, прозрачность и наличие всех runtime PNG.
- `npx playwright test tests/e2e/app.spec.ts tests/e2e/accessibility.spec.ts` — основные формы и клавиатурная доступность.
- `npx playwright test tests/e2e/map-streaming.spec.ts` — loader, bounded cache, частичная перерисовка, восстановление запросов, стабильность агентов и world-space самолёта.
- `npm run smoke:mcp` — Bearer-аутентификация, 46 инструментов, scopes, основной Streamable HTTP transport, stateless fallback и ресурсы MCP.

Большая генерация вынесена в `npm run test:scale` и не запускается вместе с повседневным набором. Основной автоматический мир ограничен одним городом и небольшим числом районов.

## Ручная карта

1. Открыть страну и дождаться исчезновения «Готовим карту…»; фон не должен становиться чёрным при панорамировании.
2. Несколько раз изменить масштаб. Люди, машины и животные в резидентной области не должны пересоздаваться или возвращаться в начальную точку.
3. Дождаться пролёта: самолёт движется относительно земли, не прилипает к viewport, выбирает один из трёх силуэтов и оставляет короткий белый след.
4. Проверить четыре вида животных и кусты; одновременно не должно быть более шести движущихся животных.
5. Навести на табличку города и границу района. Видны соответственно название города и название района с дедлайном.
6. Проверить автомобиль на горизонтальной и вертикальной дороге: кузов не касается внешнего края полотна.

## Ручная модель работы

1. В паспорте страны изменить описание, цель, продуктовый контекст, критерии успеха и ограничения одним сохранением.
2. Через MCP обновить описание/цель/deadline города, описание/deadline района и AI-поля задачи.
3. Создать связанный дефект со шагами, фактическим и ожидаемым результатом, затем перевести его в `FIXED`.
4. Перегенерировать страну: ID, статусы, комментарии, AI-поля и дефекты сохраняются; пространственная композиция меняется.
5. Убедиться, что изменение поля или дефекта перечитывает только затронутые чанки, а изменение паспорта страны не перечитывает карту.
