# Интерфейс и управление работой

Tasktopia — визуальный задачник для работы через MCP.

- Карта, поиск, карточки и документы показывают актуальные данные и позволяют переходить между ними.
- Создание и изменение задач, исполнителей, стадий, прогресса, чек-листов и комментариев выполняются через MCP. Не добавлять в UI кнопки «Взять в работу», «Назначить», «Завершить» и аналогичные команды изменения задач.
- Авторизация, личные настройки, навигация, повтор загрузки и прочтение уведомлений сохраняют необходимые элементы управления.
- Начало неназначенной задачи через MCP назначает проверенного владельца токена в той же транзакции; существующий исполнитель сохраняется. Передача — task.assign.
- Отчёты не создают собственные статусы или копии задач. На приёмке задача ещё находится в работе; завершение проходит доменные проверки.
- Новости живут в одном колокольчике. Архив хранит устойчивые знания, документы — текущее состояние работы.

Публичные инструкции агента: `public/skills/tasktopia-progress/SKILL.md`, контракт MCP — `public/ai.md` и `docs/MCP.md`.
