# QA 1.3 — навигация по странам

## Автоматические проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
DATABASE_URL=postgres://tasktopia:tasktopia@127.0.0.1:55432/tasktopia_test npm run test:e2e
npm audit --omit=dev
```

## Ручная проверка

1. Войти и убедиться, что в шапке написано только «СТРАНА», без проектной терминологии.
2. Нажать название страны: список открывается под ним, выбранная страна отмечена, клик снаружи и Escape закрывают список.
3. Переключить страну и проверить, что карта, заголовок вкладки и показатели обновились.
4. Открыть «Управлять страной», переименовать её и проверить состав правительства и ограничения ролей.
5. Создать новую страну отдельной кнопкой. В плане новой пустой страны должна появиться надпись «Нет городов» без промежуточного вечного состояния загрузки.
6. Открыть план и кликнуть по карте: панель должна закрыться. Повторить с Escape.
7. Сравнить показатели «Районов строится» и «Зданий строится» с активными районами и незавершёнными задачами.
8. Проверить ширины 375, 768 и 1440 px: горизонтальной прокрутки и наложения элементов быть не должно.
9. Проверить `/favicon.svg`, `/apple-touch-icon.png`, `/site.webmanifest`, `/social-card.png` и динамический title выбранной страны.
