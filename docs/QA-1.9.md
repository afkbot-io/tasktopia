# QA Tasktopia 1.9.0

## Связанные дефекты

1. Перевести обычную задачу в `TESTING` с прогрессом 90%.
2. Через MCP создать связанный дефект и провести его по `OPEN → IN_PROGRESS → VERIFYING`.
3. После каждого перехода убедиться, что родительская задача остаётся в `TESTING` на 90%.
4. Попытаться завершить задачу: сервер должен вернуть `OPEN_DEFECTS`.
5. Перевести дефект в `FIXED`, затем завершить задачу.
6. Повторно открыть дефект `FIXED → OPEN` и убедиться, что он снова виден как активный.

## Карта

1. На близком масштабе у `OPEN`-дефекта видна пожарная машина с маяком.
2. У `IN_PROGRESS`-дефекта видны небольшой очаг и струя; у `VERIFYING` — дым без пламени.
3. Активный `HOTFIX` показывает усиленный огонь, дым и тушение; после `COMPLETED` эффект исчезает.
4. При панорамировании и масштабе неизменный overlay не пересоздаётся, а overview не загружает incident-спрайты.
5. При включённом `prefers-reduced-motion` эффект остаётся статичным и читаемым.
