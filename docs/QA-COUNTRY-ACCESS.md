# Доступ к стране и защита аккаунта

В паспорте страны глава добавляет существующего пользователя по email, меняет полномочия «Министр» / «Наблюдатель» и отзывает доступ с подтверждением. Главу нельзя удалить или понизить. Сервер проверяет права независимо от отображения кнопок. Задачи, города, районы и отчёты остаются для просмотра; рабочие изменения выполняются через MCP.

Для нового пользователя глава раскрывает «Приглашения по ссылке», указывает email и передаёт созданную ссылку лично. Она действует семь дней, используется один раз и привязана к email. Новый выпуск ссылки отменяет предыдущую; список позволяет отозвать приглашение. Получатель регистрируется или входит на том же сервере, затем принимает приглашение. При выключенной публичной регистрации аккаунт создаёт администратор существующим CLI.

В профиле доступна смена пароля с проверкой текущего. Там же можно получить восемь резервных кодов, сохранить их вне Tasktopia и восстановить доступ через «Забыли пароль?» на экране входа. Смена и восстановление пароля отзывают все сессии, MCP-ключи и весь набор резервных кодов. После входа необходимо выпустить новый набор. В БД хранятся только хеши секретов.

Почтовый сервис не настроен: письма не отправляются. Восстановление требует заранее сохранённого кода; без него нужно обратиться к администратору.

Проверки охватывают API прав и изоляции стран, повторное/одновременное принятие приглашения, ротацию и срок действия ссылки, отзыв доступа, смену и восстановление пароля, отзыв старых полномочий и браузерные сценарии регистрации, профиля, MCP и просмотра документов. Мобильная форма и контраст элементов паспорта проверяются в Playwright/axe. Это проверка затронутых сценариев, а не всех возможных функций продукта.

Миграция 0039 только добавляет две таблицы. Перегенерация карт не требуется. Предыдущий runtime совместим с дополнительными таблицами; данные существующих стран и задач не меняются.
