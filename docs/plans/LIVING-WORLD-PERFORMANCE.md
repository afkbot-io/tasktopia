## Исправления по измерениям

- CITY начинает загрузку известных зданий одновременно с землёй; декор использует
  существующий props atlas. Повторный первый запрос сцены и лишняя сборка жителей
  скрытого города устранены. Первый COUNTRY ускорен без изменения генерации.
- «Мои»: scoped metadata cache60с с инвалидацией по ревизии/доступу/retry.
  50переключений после5прогревов: p9529,9мс desktop/61,3мс mobile,
  новыхscene-запросов0. Raw `attention-M-{desktop,mobile}.json`.
- Профиль планеты выявил2233мс в `getPointAtLength` за21с захвата.
  Самолёт теперь использует подготовленную кривую и общий sampler длины;
  точки совпадают с SVG в Chromium/WebKit с ошибкой<0,2пикселя.
  Одна эта замена не улучшила общий p95; оставалась стоимость SVGотрисовки.
- Подсветка применяется один раз к ландшафту страны, а не к каждой клетке.
  Геометрия земли сохраняется по revision; камера меняет матрицу группы.
  До этой серии mobilePLANET p95 был41,5мс; итог33,1мс. Автотест проверяет отсутствие
  замен/пересчёта SVGклеток при зуме, nearestматериалы и переход в страну.
- Эксперимент isRenderGroup для CITY полностью отклонён: улучшилp50, но неp95,
  ухудшил максимальный программный кадр. В итоговом коде его нет.
