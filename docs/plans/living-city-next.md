# Живой город: общий план реализации

Принято пользователем 5 ноября 2026 года после анализа версии1.27.1.
База: `7fbc3c82ffcecdff4a9297cd78e2f9f2492d22d3`.
Цель охватывает все пункты обсуждённого плана, а не только первый PR.

## Общая приёмка

- [ ] Камера: крестик/Escape сохраняют текущую позу; browser history отдельно;
      фокус учитывает реальное здание и свободную область, тур удалён.
- [ ] Выбор: один tooltip, читаемые номера и selected state, отсутствие поздних
      скачков при async navigation; desktop и phone.
- [ ] Постоянные остановки: устойчивые ID/координаты; навес сохраняется при
      reduced motion, переключении событий, pan/reload/LOD и подходе жителей.
- [ ] Регулярные автобусы: выделенные роли/линии/расписания, посадка/высадка,
      длинные маршруты по ограниченным сегментам, восстановление после объезда.
- [ ] Дороги: canonical extensions/gateways, hierarchy новых коридоров,
      проверка semantic/raster/directed graph; старые планы сохранены.
- [ ] Аэропорт/ЖД/порт: единый read-only выбор facility, узнаваемые support
      props и связные пассажирские/служебные сценки; реальные task endpoints.
- [ ] Общий планировщик жизни: аренда участников/площадок, приоритеты,
      конечные фазы и cleanup; быстрая первая заметная активность.
- [ ] Каталог100 событий: каждый вариант действительно подключён к runtime,
      имеет подходящее место, участников, визуальное действие и terminal state.
- [ ] Дождь/облака: world-anchored тени, намокание/высыхание и реакции жителей;
      ограниченная стоимость, интерфейс не затемняется.
- [ ] Разнообразие одного района: устойчивые локальные характеры кварталов,
      масштабируемые службы/общественные места, неизменность старых участков.
- [ ] MCP/realtime: реакции на реальные изменения, дедупликация/reconnect;
      косметические происшествия не меняют рабочие статусы.
- [ ] QA/performance:200/1000/10000 задач и увеличенная территория в одном
      районе; first frame/first life/input/frame time/memory, phone emulation.
- [ ] Документация/AI review/обязательный SCM CI/PR; точная ревизия релиза
      через managed-release, recovery/public smoke и observation.

## Порядок и доказательства

1. BUG58: навигация/камера/тур. RED→GREEN public unit seams, scoped browser
   desktop/phone; сохранить Back/Forward, отсутствие повторных scene reads.
2. Инфраструктура: постоянные остановки, выбор аэропорта, безопасные props.
3. Транспорт/дороги: persistent identity и расписание, directed path и
   append-only canonical extensions. Snapshot старой геометрии до изменения.
4. Director/events/weather: переиспользование mobility; ограниченные активные
   регионы. Каталог данных не считается готовой сценой без runtime proof.
5. Morphology/services: новый контекст только для будущих блоков;
   обогащение старой карты в свободных клетках без переноса объектов.
6. Масштабная приёмка и поставка. Успешные проверки переиспользуются только
   для совпадающих входов. Не пропускать неисправный boundary.

## Инварианты

UI рабочих объектов остаётся только для просмотра. Данные изменяются через MCP.
Одному событию соответствуют устойчивый ID, конечные фазы и безопасная отмена.
Жители и пассажиры прибывают физически; таймаут не считается прибытием.
Существующие участки/входы/terrain/дороги/rail/airfield/port не перестраиваются
ради декоративного обновления. GET не пишет планы.
Бюджеты растут от видимой области и профиля устройства, а не от всей площади.
Проверка в эмуляции не выдаётся за тест физических телефонов.

## Проверенные срезы

Камера (`3caa632d`):44 unit и20 browser-проверок desktop/iPhone;
крестик/Escape сохраняют позу, фокус учитывает карточку, тур удалён.
Проверки выбора транспорта в изолированном мире остаются в общей приёмке.

Остановки: навесы вынесены в постоянные объекты с общей сортировкой глубины.
Отключение жизни/движения и подход жителей больше не скрывают sprite;
постоянный footprint сохраняет запрет прохода. Неизменённые кадры не ищут
текстуры и не перемещают спрайты. Canonical stop read model для роста города
и регулярные автобусные линии остаются следующими пунктами общего плана.
