# QA 1.0

## Автоматический quality gate

```bash
npm run assets:verify
npm run typecheck
npm run lint
npm run test:db:start
npm test
npm test -- --coverage
npm run build
npm run test:scale
npm run test:e2e
npm run smoke:mcp
npm run test:db:stop
```

Все генераторные проверки ограничены одним городом и 10 районами. Отдельных больших профилей нет.

## PostgreSQL и перенос

1. На чистой базе обе migration-фазы фиксируются в `schema_migrations` с SHA-256; конкурентные старты сериализуются advisory lock.
2. JSONB-триггеры создают, перемещают и удаляют chunk membership, включая отрицательные координаты; смена обычного task status не перестраивает spatial index.
3. `db:import-sqlite --dry-run` не изменяет target. Реальный импорт принимает только пустую базу, сверяет source counts, constraints и sequences, не изменяя SQLite-файл.
4. Production-контейнер не стартует до healthy PostgreSQL; `/health` выполняет реальный `SELECT 1`.

## Генерация

1. Создать район `NEW_BUILD` и последовательно добавить девять жилых задач без `buildingHint`: корпуса должны заполнить один блок `3×3`, соприкасаться в рядах и не добавлять дороги.
2. Создать район `PRIVATE`: профильные задачи должны образовать улицы частных домов, а не смешиваться с высотками.
3. Заполнить все совместимые участки: только после этого район может добавить целую квартальную группу с одной улицей доступа.
4. Проверить малую тестовую страну: один город, 10 районов и 20 задач; генерация не должна создавать дополнительные города.
5. Аудит не должен находить пересечения, разрывы дорог, недоступные входы и парки или несовместимые типы застройки.
6. Границы районов по умолчанию скрыты; при включении они не должны заменять визуальную структуру кварталов.
7. В отчёте audit доля asphalt каждого `NEW_BUILD`/`PRIVATE` района не превышает 20%; в контрольном прогоне она должна оставаться заметно ниже предела.

## Карта и realtime

1. `/api/bootstrap` не содержит `districts` и `tasks`; присутствуют `initialCity`, `viewBounds` и агрегированные `stats`.
2. На дальнем масштабе `data-map-lod` равен `overview`, машины и пешеходы не создаются; initial viewport держит малый prefetch-ring.
3. Overview-чанк содержит 256 terrain cells, пустые `surfaces`/`decorations`; detail — 4096 terrain cells и полный городской слой.
4. Открытие плана последовательно вызывает `/api/plan/cities-page?limit=50`, затем районы стартового города, но не задачи. Задачи запрашиваются только после выбора района; cursor-страницы не содержат пропусков и дублей.
5. Небольшое перемещение внутри прежнего `data-chunk-range` увеличивает `data-skipped-reconciles`, но не `data-ground-rebuilds`.
6. Создание задачи или смена статуса через MCP/API не добавляет второй canvas. `data-ground-rebuilds` растёт только на число чанков, пересекающих `affectedBounds`; `data-entity-replacements` растёт только для изменившихся entity views.
7. При скрытии вкладки `data-animation-active` становится `false`; после возврата ticker возобновляется.

## Авторизация и интерфейс

1. Регистрация создаёт первую страну и открывает карту без повторного входа.
2. Вход восстанавливает выбранную страну; неверный пароль и повторный email дают понятное сообщение на русском.
3. При временной ошибке загрузки страны кнопка повторения восстанавливает сессию без повторной отправки пароля.
4. Выход возвращает экран входа, а защищённые endpoint отвечают `401`.
5. Проверить выбор страны, правительство, карточку задачи, трёхуровневый план и выпуск MCP-ключа со scopes и сроком 30/90/365 дней.
6. В новой пустой стране loader карты не создаётся; описание и кнопка «Подключить MCP» не пересекаются, кнопка кликабельна.
7. MCP-модалка открывается с видимым заголовком, показывает production endpoint, Streamable HTTP и Bearer-схему; URL и секрет копируются кнопками.
8. На ширинах 375, 768 и 1440 px нет горизонтального overflow; заголовок настроек остаётся видимым, тело прокручивается отдельно, touch-targets не меньше 44 px.
9. Axe не сообщает serious/critical WCAG-нарушений на экране входа и в MCP-модалке; Tab удерживает фокус внутри диалога, Escape закрывает его.
10. На desktop и mobile не должно быть технических или дорелизных формулировок, чёрных краёв карты и ошибок в консоли.
11. Cookie содержит `HttpOnly; SameSite=Strict`; state-changing запрос с чужим `Origin`, даже с подставленным `X-Forwarded-Host`, получает `403`.
12. После logout сокет пользователя отключается; после удаления участника он перестаёт получать события отозванной страны.
13. Приглашённый министр сохраняет write-возможности. Наблюдатель видит карту и план, может выпустить только read-scopes, а попытка `city.create` через MCP возвращает ошибку scope.
14. Отозванный, истёкший и повреждённый MCP-токен не проходит handshake. Legacy-токен без срока остаётся действительным до отзыва.
