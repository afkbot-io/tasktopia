# Глобальный аудит Tasktopia, 8 октября 2026

Проверяется тема «Хвойный атлас», runtime `f6e0adad9398cd23ab5723d3536ef26c71ab4c68`,
diff от `e6c173c7e0c4a44b2c9c3f7b379a7bebd2e34daf`. Итоговые результаты:
1493 случая Vitest, 55 Python-тестов и 201 браузерный сценарий прошли;
TypeScript, ESLint, графические проверки и HTTP MCP smoke прошли.

**Аудит пока не завершён полностью:** третью выборку последней серии
«1000 задач, 390×844» прервало отключение локального PostgreSQL. Docker Desktop
зарегистрировал `shutdown requested` в `2026-10-07T23:55:51Z`; порт 55432 исчез,
сервер получил `ECONNREFUSED`. Инструмент управления приложениями подтвердил
блокировку Mac. Требуется восстановить тестовую среду и повторить только эту
серию. Две её завершённые выборки сохранены как частичные данные и не засчитаны
в квалификацию. Остальные успешные результаты сохранены.

Изменения этого аудита затрагивают проверки, конфигурации и документацию.
Production-код, графика, зависимости, схема БД и механика мира не изменялись.
Проверены хэши 28 production inputs: изменений нет. Рабочее дерево —
`codex/forest-ui-redesign`; среда — macOS, Node 24.15.0, Playwright 1.62.1,
production build и собственные схемы PostgreSQL `tasktopia_test` на localhost.
Публичные рабочие данные для нагрузок не использовались.

## Код, типизация и исправленные проверки

Ревью сопоставляет код с требованиями редизайна и правилами репозитория.
Проверены токены, компоненты, responsive CSS, локальные шрифты, PWA-кэш,
доступность, обработка ошибок, отмена устаревших запросов, изоляция страны,
MCP/HTTP-авторизация и UI для просмотра. Карта поверхностей и 41 исходный
компонент перечислены в [плане дизайна](design/FOREST-ATLAS-REDESIGN-2026-10-08.md).

В приложении есть PLANET и CITY; отдельного режима COUNTRY нет. Кнопки
изменения рабочих объектов не возвращены. Настройки аккаунта, доступа,
MCP и обмена ссылками соответствуют [продуктовой границе](PRODUCT-UI-RULES.md).

Исправлены подтверждённые пробелы проверок:

- `tsconfig.json` включает корневые `*.config.ts`, в том числе Vitest и обе
  конфигурации Playwright. Строгая проверка этих файлов проходит.
- Courtyard-art fixture создаёт родительский `tmp` перед `mkdtempSync`.
  В чистом checkout три случая падали с `ENOENT`; итоговые пять проходят.
  Временные каталоги остаются под репозиторием для Python-verifier и удаляются
  после теста. Системный `tmp` несовместим с поиском scripts этим verifier.
- Три сценария недоступности карточки используют реальные команды MCP с явным
  `countryId` и собственным ограниченным ключом. Ключ отзывается и собственная
  задача удаляется при teardown. Устранены удалённые HTTP-команды и ожидание
  кнопки переноса. Проверяются 403/404, сохранение данных при 503 и восстановление.
- Navigation-cache использует текущий вход через PLANET и учитывает
  клавиатурную активацию. Имитация 503 держит сервис недоступным до восстановления:
  reconnect и replayed rename могут независимо инвалидировать сцену. Trace
  показал, что второй запрос при прежней одноразовой имитации обрабатывал новое
  событие. После burst тест запрещает самопроизвольные повторы до «Повторить».
- Добавлена отдельная матрица устройств. Штатный CI запускает её только явно.
- Измеритель сохраняет long tasks, heap после принудительного GC и повторных
  переходов. При ошибке теперь сохраняет незавершённый отчёт с причинами и
  уже полученными выборками. Отдельная имитация отказа 503 подтвердила сохранение
  отчёта и закрытие браузера. Helper навигации явно проверяет успешный bootstrap
  и наличие города, чтобы HTTP-отказ не маскировался ошибкой чтения `undefined`.

Production-дефект, требующий изменения поведения приложения, в выполненных
проверках не подтверждён. Это вывод в пределах указанного покрытия.

## Производительность

Условия и бюджеты объявлены до запуска в
`.builder/global-audit/performance-plan.md`. Production runtime неизменён,
Chromium 151.0.7922.34, Apple M5 Pro, настоящий Metal renderer, NORMAL,
DPR 1, localhost без ограничений сети. В каждой завершённой ячейке три новых
контекста, 3 с прогрева и 8 с наблюдения кадров. Показана медиана и полный
диапазон; p95 загрузки по трём выборкам не вычисляется.

`coldMs` — от активации города до атомарного commit сцены; `interactiveMs`
дополнительно ждёт исчезновения переходного перекрытия. `appMs` включает вход
на страницу и PLANET. Это отдельные показатели, не время от клика иконки сайта
на физическом телефоне. Последовательные серии не запускались одновременно
с серверной нагрузкой.

Все пять завершённых ячеек уложились в объявленные бюджеты:
cold ≤3 с для 40/300 задач, ≤5 с для 1000; warm ≤500 мс; p95 кадра ≤50 мс.
В каждой выборке один cold scene, ноль legacy viewport/chunk запросов,
ноль неожиданных ошибок и ноль long tasks в спокойном измеряемом интервале.
Geometry hash совпадает между выборками и окнами одного мира. Для 300/1000
создано 18/60 chunks реальным генератором; `auditWorld` нашёл 0 нарушений.

На 1000 задач после 20 возвратов в каждом из трёх desktop-контекстов рост heap
после GC составил 0,67–0,82 MiB, медиана 0,75 MiB при бюджете 5 MiB.
Canvas сохраняется, скрытая сцена останавливает анимацию. Heap около 256 MiB
остаётся заметной стоимостью большой сцены; данный замер не доказывает
достаточность памяти слабого телефона и не измеряет всю GPU/OS-память.

Частичные compact-выборки: cold 2146/2095 мс, warm 82/67 мс, p95 кадра
10,1/10,2 мс. Их полный итоговый JSON не успел записаться прежним измерителем;
числа восстановлены из stdout. Серия требует нового полного запуска.

Серверный аудит: собственная схема, 100 задач, 6 районов, 20 warm-выборок,
SQL plans и штатные бюджеты. Все бюджеты выполнены. Cold city — 109 мс,
cold country — 46 мс; warm p95: task 8,31 мс, city 5,35 мс, country 20,98 мс,
planet 21,13 мс, смена стадии 73,57 мс. Восьмерное конкурентное чтение —
73,16 мс p95, две конкурентные записи — 148,91 мс. Это серверные измерения,
а не полное браузерное время ответа.

Отдельно: warm-карточка 3,2 мс; 20 переходов PLANET/CITY — 10,1–95,3 мс,
без чтения world scene и с сохранением камеры/canvas. Движение наблюдалось
120,1 с: 76 поездок, 614 переходов пешеходов, один build сети, step p95 0,8 мс,
max 3,4 мс. Headless SwiftShader дал p95 кадра 25,1 мс и один long task 55 мс;
это проверка корректности симуляции, отдельно от квалификации Metal renderer.
Ожидаемый начальный 401 и startup warnings драйвера отмечены отдельно;
неожиданных ошибок приложения/сети и application GPU readbacks нет.

Предыдущая попытка mobility получила 500 после ручного reseed живой схемы:
fixture сбросила `world_version`, сервер сохранил более высокий revision fence.
После перезапуска собственного QA runtime тем же build тест прошёл.
Такой reset БД вне API не является поддерживаемой рабочей командой.
Диагностика `residentCenterErrors` сравнивает необработанные координаты с
намеренно округлёнными pixel-позициями спрайтов; её ненулевое значение само
по себе не подтверждает неправильную ориентацию жителей.

Это baseline текущей версии. Ускорение относительно прежнего дизайна и работа
на любой мощности устройства по этим измерениям не заявляются.

## Зависимости и остаточное покрытие

Шесть moderate-записей относятся к Fastify, Vitest/mocker/coverage, fast-uri
и ip-address. Порог high пройден, но audit не является чистым. Условие
Fastify HTTP2+trailers не найдено в HTTP1-приложении; Vitest browser-mock
endpoint не выставлен наружу. Это проверка достижимости, не доказательство
отсутствия всех возможных атак. Совместимые patch-обновления остаются долгом
перед следующим выпуском. Первичные описания:
[Fastify](https://github.com/advisories/GHSA-4mh8-r7rc-xpvc),
[Vitest](https://github.com/advisories/GHSA-82fw-gwwq-j7x9).

Пропуски не считаются passed. Из 47 исходных skipped отдельно прошли 7:
ground-cache, два navigation-cache, три task-modal-unavailable и mobility.
Остаются 40: специализированные art/transport/scale fixtures, renderer prototype,
документационные captures и ограничения WebKit/CDP/PWA. Каждый случай с причиной
записан в [сводном JSON](evidence/global-audit-2026-10-08/summary.json).
Ранее просмотренные 130 стадий зданий/парков используют неизменённые PNG;
их доказательства повторно используются из
[аудита графики](QA-CITY-ART-LOAD-AUDIT-2026-10-07.md), без заявления нового
покадрового просмотра всех этих стадий.

Профили устройств эмулируют экран, touch и DPR на macOS. Физические iOS/Android,
Windows/Linux GPU-драйверы и установка iOS PWA не квалифицированы этим запуском.
Docker/Linux integration восстановления, аварийный rollout, SCM CI и managed
release в этот локальный аудит не входят. 55 Python unit проверяют драйверы
на mock/temp-границах и не заменяют настоящий backup/restore.

Публичная проверка `tasktopia.online`: `/` 200 (2,70 с), `/health` 200 (1,74 с),
`/mcp` без ключа 401 (0,66 с), версия 1.24.12. Авторизованный read-only MCP
`country.get` успешно прочитал закреплённую страну из базы, worldVersion 675.
Это одиночные проверки доступности, без нагрузки и изменения рабочих данных.
Новый дизайн этим аудитом не опубликован.

## Доказательства и продолжение

[Сводный JSON](evidence/global-audit-2026-10-08/summary.json) хранит SHA, исходные
показатели, перечень browser-cases/skips, ограничения и хэши основных отчётов.
Полные логи/JSON/traces/PNG доступны локально в `.builder/global-audit/`.
Результаты относятся к runtime SHA и указанным условиям; повторная сборка
живого preview при неизменённых production inputs не требуется.

После восстановления Mac и PostgreSQL проверить, сохранилась ли собственная
схема 1000 задач: тестовый контейнер использует tmpfs. При необходимости
пересоздать только собственный изолированный fixture, проверить `auditWorld`,
перезапустить только его runtime и повторить `AUDIT_SAMPLES=3`,
`AUDIT_COMPACT=true`, `AUDIT_CHURN_CYCLES=20`, `AUDIT_HEADED=true`,
`AUDIT_QUALITY=NORMAL` через `scripts/measure-city-loading-audit.ts`.
Обновить последнюю ячейку и статус отчёта по результату. Успешные независимые
проверки неизменённого runtime повторять не требуется.

Расширенная матрица: `npx playwright test --config=playwright.devices.config.ts`.
Для изолированного production-сервера задать `E2E_BASE_URL`,
`E2E_DATABASE_URL`, `E2E_WEB_COMMAND=false`, `E2E_SEED_COMMAND=true`.
После нового seed перезапустить собственный QA runtime до тестов, чтобы
fixture не нарушала revision fence уже работающего процесса.
