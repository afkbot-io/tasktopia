# Страны, палата и права доступа

## Модель

- Один аккаунт может основать сколько угодно стран.
- Новая регистрация автоматически создаёт первую страну и делает её активной.
- Владелец страны называется основателем. Приглашённый пользователь называется членом палаты.
- Человек может одновременно состоять в палатах нескольких стран и выбирать активную страну в вебе или через `country.select` в MCP.

## Права

Основатель и член палаты могут открывать карту, читать города/районы/задачи и выполнять обычные MCP-команды развития выбранной страны. Только основатель может:

- пригласить зарегистрированного пользователя по email;
- исключить члена палаты;
- удалить страну.

Основателя нельзя исключить через endpoint палаты. Член палаты не видит действие удаления. Сервер независимо проверяет роль и возвращает `403`, поэтому скрытие кнопки не является механизмом безопасности.

Приглашение не отправляет письмо в MVP: email служит точным идентификатором уже зарегистрированного аккаунта. Неизвестный email возвращает `404`, повторное приглашение — `409`.

## Персональный MCP

MCP-ключ принадлежит аккаунту, а не стране. В базе хранится только hash. Перевыпуск отзывает предыдущие активные ключи этого аккаунта. На каждом MCP-запросе сервер заново разрешает активную страну и роль пользователя, поэтому:

- исключённый участник сразу теряет доступ к стране;
- переключение страны действует со следующего stateless MCP-запроса;
- создатель задачи и автор изменений берутся из владельца ключа;
- ответственного можно назначить только из текущей палаты.

## Хроника задачи

Задача хранит `creator_user_id` и `assignee_user_id`. Отдельная append-only таблица фиксирует создание, смену стадии, комментарий и назначение. Событие содержит отображаемое имя, необязательный user id, детали и серверное время. Карточка задачи показывает создателя, ответственного, комментарии и хронологию действий.
