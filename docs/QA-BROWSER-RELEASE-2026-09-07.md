# RELEASE14: актуализация браузерного release gate

Исходная ревизия `289a391315befcacf04615884ba81a9824516cdc`:
[CI 34130197914](https://github.com/afkbot-io/tasktopia/actions/runs/34130197914)
прошёл assets, types, lint, unit, build и MCP, но завершился с четырьмя
ошибками E2E (25 passed, 43 skipped). Audit в этом CI не запускался.

## Причины и исправления проверок

- Локально воспроизведены два детерминированных падения: `448` общих
  world objects сравнивались с `1189 / 4` декораций, а единственный город
  должен был иметь межгородские авиарейсы. Теперь группировка сравнивает
  только статические декоративные слои с их элементами с прежним коэффициентом
  `1/4`, дополнительно проверяется корректность порядка глубины. Для одного
  города требуется ровно ноль рейсов и элементов самолётов. Положительный
  сценарий двух аэропортов остаётся в отдельном country-overview fixture.
- CI зафиксировал возврат за 1030,7 мс при лимите 1000 мс. Старый замер
  включал ожидание доступности кнопки, последовательные команды драйвера и
  polling assertions. Новый замер идёт в браузере от реального click до
  активной атомарной сцены без очереди земли и без перекрывающего перехода,
  включая возможность отрисовать кадр. Лимит **1000 мс не увеличен**.
  Два независимых теста на DOM показывают: ожидания драйвера не учитываются,
  реальная задержка активации 1100 мс учитывается и превысит этот лимит.
- Безусловные серии отдельных wheel-команд могли пересекать несколько
  жестов на медленном runner: в текущем контракте пауза свыше 220 мс
  разрешает следующий переход. Проверка одной границы теперь отправляет
  одну достаточную wheel-дельту; следующий намеренный жест начинается
  после явной паузы. Это соответствует текущему обработчику без изменения
  production-кода. Локально старые проверки времени и wheel не падали;
  воспроизведения именно нагрузки CI нет, результат нового CI обязателен.

## Выполнено локально

Изолированный PostgreSQL из `docker-compose.test.yml`, отдельный проект
`release14-e2e-289`, production build исходной ревизии на порту 27415.
Runtime не менялся; изменены только тесты и этот отчёт.

- Исходные три spec: 7 passed / 2 failed, подтверждены указанные ожидания.
- Первый исправленный набор: 10 passed.
- Итоговый `playwright test --project=chromium --workers=1`: **27 passed,
  41 skipped**, 1,2 минуты. Skipped — существующие сценарии с отдельными
  fixture-флагами; новых skip нет, их прохождение здесь не заявляется.
- Итоговые `npm run typecheck`, scoped ESLint, `git diff --check`: PASS.
- `npm audit --audit-level=high`: 0 vulnerabilities.
- Основной агент прочитал точный diff и новые файлы; подтверждённых
  замечаний не осталось. Это не human review и не production acceptance.

Удалённый CI нового коммита, merge и production deployment ещё не выполнены
на момент подготовки отчёта. Runtime, миграции, ассеты и deployment guards
не изменены. Для первого compact cutover по-прежнему необходима отдельная
проверенная инфраструктурная доработка; обхода штатного updater нет.
