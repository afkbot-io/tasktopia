# Наземные дороги на активной планете

Активный интерфейс PLANET → CITY теперь получает сохранённые межгородские
дороги. Ранее отдельный COUNTRY API содержал их проекцию, но текущий
PlanetAtlasCanvas не показывал линию. Дополнительный режим страны не нужен.

## Данные и география

PLANET6 добавляет необязательный `countries[].groundRoads`. Один JOIN
по UUID доступных стран читает revision и `plan_json.routes`; дополнительных
запросов на каждый маршрут нет. Поля публикуются по whitelist, концы должны
принадлежать городам той же страны. Права и новая геометрия входят в ETag.
GET не меняет дороги, задачи, участки или остановки. Существующая отдельная
инициализация личной географии сохраняет прежний контракт.

Все входы ограничены:1024 проверенных маршрута суммарно,100 на страну,
16384 проверенных run и300000 клеток принятой геометрии. Отсутствующий
снимок, неверные данные и пропуски различимы. Клиент принимает6 и прежний5;
при5 он не рисует наземные дороги. Старому клиенту после выпуска6 нужен
refresh. Новых миграций и PNG нет.

Проекция сохраняет route ID и неподвижные городские якоря. Упорядоченные
samples исходной геометрии проходят только через унаследованные сухие
4-связные macro cells. Краткий локальный обход использует существующий
atlasGridPath; это картографическая проекция принятой связи, а не поиск
новой мировой дороги. Укрупнение клеток может изменить форму линии.
Разрыв суши, неизвестный якорь, невозможный порядок или исчерпанный бюджет
означают явный unavailable. Прямая линия по воде не создаётся.

Общие пределы подготовки:16384 grid cells,40000 samples,2млн сравнений,
100000 консервативно оплаченных search cells и по50000 output points/cells.
Один локальный BFS ограничен4096 сухими клетками страны; фактически текущая
личная география содержит не более144. Cooperative runner возвращает
управление через bounded checkpoints;4мс — мягкий бюджет, не гарантия
длительности любого синхронного шага. Отмена владельца прекращает подготовку.

## Рисование и ресурсы

Переиспользуются существующие country-road-render и approved asphalt/pavement
из road-v2. Одна macro cell занимает16 native pixels:3px асфальта,5px покрытия.
Все прямоугольники целочисленны, clipped к доказанной суше. Отсутствующие,
водные и неизвестные клетки не становятся газоном для рисования дороги.
Линия лежит ниже городских миниатюр, не перехватывает выбор.

Один raster на страну/revision; pan/zoom меняет только общую матрицу.
Максимум2048px по стороне,4096 клеток bbox и2097152 raster pixels суммарно.
При превышении страны её линии отклоняются до выделения canvas. Временные
canvas очищаются в finally, включая ошибку и abort. При ошибке загрузки
используется существующий alert с кнопкой «Повторить»; ready публикуется
после завершения terrain и road raster вместе.

## Проверки и пределы доказательств

Public RED→GREEN: отсутствие road read model на HTTP, отсутствие projection/
raster seam, неверный revision. Unit/API охватывают whitelist/privacy,
лимиты, права и отзыв участия, ETag/304, read-only строки БД, старый schema5,
сушу/острова, порядок изгибов, якоря, целочисленные pixels и отмену.

Scoped browser проверяет реальные route IDs и пиксели итогового кадра,
CITY-выезд, close без сброса камеры, возврат того же canvas, один scene GET
без viewport/chunk reads и рабочих UI writes. Дополнительные режимы:
`E2E_ROAD_FAULT=true` — холодный отказ PNG503 и восстановление кнопкой;
`E2E_ROAD_REALTIME=true` — рост через настоящий MCP и новый road revision;
`E2E_ROAD_TALL=true` — desktop1440×1100. Материалы CITY и PLANET общие,
поэтому отказ вводится до прогрева decoded image cache городом.

Предельный синтетический read model:1100 исходных дорог в11 странах,
1024 приняты и76 пропущены,1584 dry cells,23552 output cells,405504 raster
pixels,217993 байта JSON. Три пары отдельных Node24 процессов показали
медиану синхронной проекции127,1→29,0мс после удаления копирования всей суши
для уже соседних samples. SHA проекции и raster plan совпадают; cooperative
вариант делает205 уступок. Это изолированная фаза, не замер загрузки10тыс.
задач или полного браузерного кадра.

64 unit/API проверки в16файлах проходят. Production build/typecheck/scoped
lint и fixed AI/security review проходят. Итоговый browser v9: desktop
1440×1100, Android Pixel7 и iPhone13 —3PASS без retry, после zoom и обычных
переходов. Положительные probes сравнивают native road PNG с пикселями
реального screenshot с учётом SVG matrix/DPR и brightness. Просмотрены
итоговые кадры всех3профилей; подписи могут закрывать часть маленького
острова, дорога остаётся видна на ближнем обзоре. Каждый сценарий сохраняет
один scene GET, тот же canvas,0chunk/viewport reads/рабочих UI writes,
успешный Retry после503 и новый road revision после реального MCP growth.
Screenshot readback в Chromium/Android даёт диагностические Performance/
ReadPixels предупреждения драйвера: они сохранены отдельно. GL draw errors,
passive misuse, Pixi deprecations и неожиданные console/page errors запрещены.

Этот прогон выявил и после исправления подтвердил связанный Safari-дефект:
RAF-камера превышала ограничение History API и роняла весь React UI.
Описание и отдельные проверки — [сохранение позы](58-history-pose-rate.md).
Его33 навигационных browser-кейса и30unit учитываются отдельно от64road tests.

Общая квалификация200/1000/10000, иерархия новых коридоров,
транспортное оформление, SCM и управляемый релиз остаются отдельными
пунктами общей цели. Принятый маршрут не доказывает связность всех городов.
