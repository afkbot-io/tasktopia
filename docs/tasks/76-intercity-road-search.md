# Ограниченный поиск межгородских дорог

На открытой суше с настоящими perimeter nodes (0,0) и (800,800) прежний
планировщик тратил 8000 состояний с одинаковой оценкой и возвращал
`ROUTE_BUDGET`. Версия 3 при равной полной оценке сначала рассматривает
кандидата с большим пройденным расстоянием. Последний порядок по номеру
добавления сохраняет детерминизм. Контрольный маршрут находится за 301
состояние при тех же пределах.

Проверки всей ширины дороги, защитного зазора, участков, исторических мест,
остановок, транспортных площадок, воды и мостов сохранены. Прежние дороги
проверяются и остаются побайтово теми же объектами геометрии; новые связи
только добавляются. Отказ означает отсутствие пути в конечном окне
и бюджете, а не доказательство недоступности всей географии. Отдельная
контрольная карта с 200 задачами пока даёт конечный отказ; это не объявляется
исправленным случаем и не оправдывает дорогу через защищённую территорию.

## Обновление страны

Ключ повторного использования включает road topology hash и версию
планировщика. Снимок 2 или без версии может обновиться один раз до 3
при прежнем checksum улиц. Актуальный снимок возвращается без поиска.
GET карты читает сохранённые данные и не запускает обновление.

В рамках управляемого выпуска, после backup/recovery проверок и
`transport:synchronize`, выполнить для каждого явного UUID страны:

```sh
npm run roads:synchronize -- --country <UUID>
npm run roads:synchronize -- --country <UUID> --write
npm run roads:synchronize -- --country <UUID> --write
```

В собранном серверном образе использовать `node dist/synchronize-roads.mjs`
с теми же аргументами. Нужна переменная `DATABASE_URL`; команда не применяет
DDL. Первый запуск только рассчитывает отчёт. Запись под блокировкой страны
публикует снимок, увеличивает `world_version` и удаляет сохранённые overview
и chunk payloads одной транзакцией. Повтор должен дать `changed: false`
и тот же checksum, без изменения мира и геометрии задач. Успешный отчёт
печатается после commit. Неверные аргументы и неизвестная страна отклоняются.

Checksum относится к маршрутам; при сохранении всех прежних связей
он не меняется. Он может измениться при добавлении подтверждённой связи.
Проверять реальные `unreachable` в отчёте, а не требовать искусственной
связности всех островов. Не выполнять перегенерацию ради визуального выезда.

Откат — только управляемый совместимый выпуск с сохранением дорог и
резерваций остановок. Возврат старого образа требует проверки его способности
валидировать уже сохранённые маршруты; не удалять данные для обхода отказа.

## Проверки

Public RED→GREEN охватывает открытый Manhattan plateau, смену версии при
неизменном checksum и read-only preview. Связанные проверки включают воду,
мосты, ограниченные ресурсы, защитные зоны, сохранение дорог при росте,
транзакционный откат, явную страну, CLI dry-run/write/repeat и сброс проекций.
Браузерная проверка desktop/Android/iPhone сверяет опубликованные дороги
в CITY/PLANET, сохранение камеры при закрытии задачи, возврат готового canvas,
отсутствие дополнительных scene/viewport/chunk reads и рабочих UI writes.
Итоговые результаты и ограничения фиксируются после выполнения проверок.

## Проверенный технический срез и оставшаяся работа

79 уникальных проверок в 13 файлах проходят: основной набор 74/11,
дополнительно release preflight 2 и восстановление истории 3. CLI отдельно
проверен с аварийным отказом публикации: снимок и версия мира откатываются,
успешный stdout отсутствует. В старом тесте истории исправлено ожидание,
что все features — маркеры руин: теперь маркеры проверяются отдельно,
а полный набор features — на идемпотентном повторе после пересборки.
Types/scoped lint/production build проходят.

Три пары отдельных Node24 процессов на фиксированном исходнике `cba7663a`
подтверждают 8000→301 состояний для открытой суши. Медиана этой отдельной
фазы — 171,4→18,5 мс. Контрольный native200 случай остаётся с
`ROUTE_BUDGET` и 8000 состояниями в обеих версиях; улучшение не устраняет
все конечные отказы поиска.

Финальный браузерный сценарий v4 проходит на desktop/Android/iPhone без
повторов runner. Локальный выезд виден после обычного pan, закрытие задачи
сохраняет камеру, возврат сохраняет canvas и один scene GET, viewport/chunk
reads отсутствуют. Поиск точки для снимка учитывает местную границу города:
первый конец ориентированного маршрута может принадлежать далёкому городу
и находиться за штатным ограничением камеры. Это не основание расширять clamp.

Просмотр кадров выявил незавершённую часть AC-003: активный PLANET
не рисовал наземные дороги, хотя отдельный COUNTRY API их возвращал.
Связанный [срез77](77-planet-ground-roads.md) подключает read-only PLANET6,
унаследованную dry projection и прежний country-road-render к активному
компоненту.64unit/API и3live browser desktop/Android/iPhone подтверждают
права, ETag, видимые pixels, stable route IDs, Retry после503 и настоящий
MCP growth. Линия проверена в текущем интерфейсе, без режима COUNTRY.
Обнаруженный в этом прогоне Safari history rate crash исправлен отдельно.
Общая квалификация 200/1000/10000, SCM и управляемый релиз ещё не выполнены.
