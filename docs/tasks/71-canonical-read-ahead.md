# Ограниченная подготовка физических страниц

`CanonicalCityProjection` поддерживает ширину1или2. Значение по умолчанию
остаётся1. Приложение выбирает не больше2по прежней оценке числа ядер.
Город по-прежнему включает все576страниц и10 000задач контрольной карты.
Координаты, входы, покрытия, порядок и алгоритмы физики не меняются.

Одновременно хранятся не больше двух ожидаемых результатов. Ответы могут
приходить в любом порядке, а принятие идёт по исходному индексу. Только
полная подготовка заменяет предыдущий готовый снимок. Rejection-handler
присоединяется сразу при запуске чтения, поэтому ранняя ошибка следующей
страницы или поздняя ошибка отменённого запуска не остаётся необработанной.
При обработке ошибки отменяются остальные чтения этого запуска. Старый
готовый город сохраняется, признак pending позволяет явный retry.
Кэш contentHash/stages и кооперативные границы4ms сохранены.

Каждый запрос проекции лениво создаёт собственный `ChunkMaterializer`.
Чтение начинается после первого настоящего atomic-кадра. Неизменные страницы
берутся из кэша и не создают worker. Общая очередь визуальных страниц
остаётся отдельной. Временный физический пул освобождается в finally при
успехе, ошибке или отмене; teardown очищает ещё живых владельцев.

Необязательный ownerSignal конструктора materializer подписывается раньше
отдельных запросов. Отмена запуска уничтожает весь принадлежащий ему пул
без создания замен для каждого отменённого worker. Поздний finally старого
запуска закрывает только его локальный пул. Отдельный запрос, другой запуск
и визуальный пул сохраняют прежние правила владения и восстановления.
