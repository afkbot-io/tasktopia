# Память индекса маршрутов

Задача 83: `204572ae-4998-4463-8a26-fa853ad54546`, страна
`4201d605-751a-469b-8d5f-a7e322a7ece1`. База — `25796a58`.
Общий релиз живого города ещё не выполнен.

## Изменение

Скомпилированные автомобильный и пешеходный графы уже хранят координаты
в Float64 snapshot. Дополнительный string→node Map заменён числовой hash
таблицей для уникальных signed32 integer координат. Слоты Uint32 содержат
node+1; поиск не выделяет координатную строку. Snapshot, CSR, original Cell
metadata/identity в reachable results, направленность, порядок связей,
heading, closures и лимит 8 000 состояний поиска сохранены.

Построение и поиск ограничены 64 probes. Дробные/слишком большие координаты,
дубликаты или патологическая цепочка коллизий используют прежний Map.
Числовой путь ограничен 8 388 608 узлами, при превышении тоже используется
прежнее представление. Публичные adjacency/closure keys принимаются только
в прежнем точном написании: пробелы, лишние запятые, leading zero и `-0`
не становятся новыми существующими ключами. Порядок итерации — графа,
а не слотов. Каждый шаг построения остаётся cooperative/cancellable.

Отдельный RED выявил потерю custom `NaN,0`: физический snapshot прежде
нормализовал NaN в ноль, а индекс сохранял исходный ключ. Редкие отличия
исходного ключа от физического snapshot теперь сохраняются отдельно и
включают Map fallback. Float64 не заменён на Int32, произвольные custom
координаты не обрезаются. Новых API, схемы БД, PNG или UI нет.

## Измерение

Public GC probe удерживает оба исходных графа, проверяет настоящий маршрут
и включает typed-array backing storage. На 65 536 узлах / 261 120 связях
скомпилированная сеть занимала 6 794 884 байта, теперь 3 943 980. Новый
предел 4,5 МиБ сначала дал RED, затем GREEN. Нельзя переносить эту стоимость
Node-процесса в прогноз браузерной памяти без отдельного измерения.

Три чередующиеся пары на сохранённом native10000/576chunks, свежие Chromium
и сервер, Metal M5 Pro, 1440×1000/DPR1, одинаковая геометрия и seeded physics:

| Медиана | До | После |
| --- | ---: | ---: |
| main heap | 469,03 МиБ | 458,67 МиБ |
| main + backing | 515,61 МиБ | 511,25 МиБ |
| Первый atomic кадр от direct CITY URL | 2 443 мс | 2 346 мс |
| Полная физическая готовность | 16 946 мс | 16 682 мс |

Чистая экономия — 4 573 119 байт, 4,36 МиБ. Увеличение backing на 6 МиБ
учтено, а не скрыто за main heap. Во всех шести запусках 10 000 задач,
576 физических страниц, один scene GET, decode pools 0, ошибок нет.
Это отдельный direct CITY профиль, не официальный полный journey или
физический телефон. Старый HTML переключался только на своём локальном
сервере и восстановлен в finally; хеши и все исходные результаты сохранены.

Первоначальный прогноз 16 МиБ **не достигнут**. Исходный FAILED
`index83-paired.json` и его runner не переписаны, прогоны не повторялись
ради выбора лучшего результата. Измеренная native стоимость оказалась
меньше предварительной модели. Прогноз агента уточнён до 4 МиБ в brief/task
v2 с read-back; та же неизменная серия проходит этот ориентир и предел
регрессии времени 5%. Это не прохождение прежнего порога 16 МиБ и не
изменение цели пользователя. Общий ориентир 256 МиБ всё ещё не достигнут.
