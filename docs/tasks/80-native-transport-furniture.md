# Постоянные детали транспорта и материалы аэродрома

Аэродром использует принятые8×8 материалы городских дорог: pavement, asphalt,
driveway и pavers. Разметка остаётся целочисленной. Стадии1–2 используют
землю и ограждение,3 — подготовленное покрытие и земляную полосу,4–5 —
прежние рулёжные пути/стоянки и готовую разметку. План38×14, входы, runway,
taxi, stands и пассажирские клетки не меняются.

Материалы собираются в один Graphics без дополнительных Sprite на клетку.
Ground signature исключает повторную сборку при неизменном плане. В Pixi
`textureSpace:local` растягивает весь source atlas; native subframe требует
global UV с переносом начала каждой клетки. Этот дефект был найден просмотром
снимков после успешного функционального прогона и закрыт реальной проверкой
пикселей GPU-кадра: прежний код0/64, исправленный≥60/64 на трёх профилях.
При сравнении учитывается только единый существующий world-light tint.

## Два authored предмета

`airport-windsock` и `rail-platform-clock` имеют native canvas16×16,
bottom-centre anchor8,16, hard alpha, не более8 непрозрачных цветов и1×1
нижний физический контакт. Камера frontal-top/high45, свет сверху слева,
slate/cream/terracotta соответствуют существующим скамейкам и светофорам.

Источники созданы встроенным imagegen; полные prompts и source-pinned
normalization находятся в
`assets/pixel-city-pack/reference/ai-authored/transport-furniture-v1/`.
Существующий арт не перерисован и не повёрнут. Два ранних варианта часов
отклонены: сначала терялся циферблат, затем вертикальная стрелка. Принимается
только третий source с читаемым L; код выполняет threshold/crop/равномерный
nearest-neighbour/quantize и регистрацию исходной опоры. Normalized PNG не
дорисовывается. Native и8× preview, затем шесть actual CITY4× кадров просмотрены.

После упаковки нового атласа все146 прежних props сохранили метаданные и
точные RGBA пиксели. Добавлены два ключа; прежние terrain/buildings/boats/
people/vehicles не меняются. `assets:verify` дополнительно проверяет source,
normalization, review, геометрию, обе опубликованные копии и пиксели atlas frame.

## Размещение и жизненный цикл

Один общий resolver выдаёт позиции для renderer и walking blocker.
Разрешены только stage5/COMPLETED существующей задачи нужной serviceRole.
ID образован из task ID и роли предмета. При удалении владельца предмет
освобождается; при pan/reload/качестве/reduced motion и отключённой жизни
положение и видимость не зависят от анимационного контроллера.

Указатель ветра занимает один из двух боковых карманов внутри зарезервированного
аэродрома. Часы проверяют четыре кармана у торцов платформы внутри прежнего
защищённого railway corridor. Их высокий силуэт исключает3×2 envelope из
пассажирских access/bridge/platform/boarding клеток. Нельзя занимать runway,
taxi, stands, дороги, соседние пути или воду. Бизнес-участки уже исключены
каноническим серверным резервированием; runtime дополнительно проверяет
terrain/roads/surfaces локальными lookup. Весь каталог задач не обходится.

Если места нет, предмет не появляется: на настоящем seed1 из QA торцы
платформы оказались на береговой/водной полосе. Это сохранено как regression,
а успешный lifecycle проверен на сухом seed424242. Земля и планы ради декора
не подменяются. Отдельный грузовой apron старого порта не добавляется: его
нынешний контракт не резервирует для этого сушу. Прежний terminal/pier остаётся.

Обработка ограничена32 airport records, двумя кандидатами каждого, одной
railway с четырьмя кандидатами и6 локальными free lookup на кандидата.
Access свыше4096 отклоняется до перечисления; неправдоподобные координаты
не запускают построение длинного passenger path. Постоянные Sprite сохраняются
между кадрами и повторяют lookup отсутствующей текстуры без замены объекта.

## Доказательства и границы

Public RED→GREEN покрывает отсутствие resolver/view/material seam, immutable
placement, воду/препятствия/неверную роль/удалённого владельца/стадию,
вертикальный corridor, другую сторону платформы, malformed/oversized access,
native anchors, retry и cleanup.41 уникальная unit/integration проверка
в10 файлах; неизменные связанные проверки переиспользованы.
Отдельный RED→GREEN сохраняет apron старых cached сцен без поля airports;
новые canonical сцены читают только явные terminal IDs и не обходят весь город.

Actual MCP на собственной локальной стране,200 задач/один район: TESTING→
COMPLETED обоих terminal tasks, native pixels, pan/zoom, качество, life,
reduced motion, reload, снос аэропорта и cleanup. Геометрия block/slot/access
и канонические transport планы сохранены. Проверки используют desktop1440×1100,
compact Pixel7/iPhone13; они не являются тестом физических устройств.
Это локальный срез общей цели, не итоговая квалификация1000/10000 или релиз.

Дополнительно три существующих actual AIR/RAIL/SEA inspector сценария на
изолированном транспортном мире проходят: выбор настоящего транспорта,
добровольное слежение/отмена, reduced motion и открытие действующей задачи.
Wholepack build→verify выполнялись последовательно; новый published source/
atlas gate проверен отдельно для тех же неизменных PNG. Build/types/lint и
fixed root AI-review проходят, открытых замечаний нет. Это не SCM approval.

Откат — общий client/asset revision. HTTP/MCP/SQL, маршруты и рабочие данные
не требуют миграции. Отдельные искусственные рейсы не добавлены.
