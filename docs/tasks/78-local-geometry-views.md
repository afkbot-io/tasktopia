# Локальные реакции без копий всей карты

Начало стройки копировало пешеходный Map и дорожный Set, а затем повторно
перебирало все пешеходные клетки ради шести строителей возле одного участка.
На native10000 это507235 walking cells и321789 road cells. Дополнительно
prepareLife удерживал объединённый Set741017 клеток, уже представленных
исходными blocked/road/parking индексами.

## Поведение и владение

Строители получают только `has/get` walking index и дорожный `has`. Кандидаты
ищутся в двухклеточном halo native footprint, пути остаются в прежнем
четырёхклеточном пределе. Прежние сортировка, приоритет входа, направления,
порядок путей и исключения занятых клеток сохранены. Фактические клетки
с графа переиспользуются так же, как в прежнем алгоритме. Water/unloaded,
дороги, здания, жители и чужие бригады не становятся доступными.

Текущие/следующие клетки жителей с halo1 образуют маленькую отдельную маску.
Полный walking Map не копируется и не изменяется. Маска запрашивается
синхронно при начале cinematic у текущего renderer owner; результатом
остаются только короткие пути, существующие lease и cleanup не меняются.

Пустой/нецелочисленный/небезопасный footprint, свыше4096клеток или extent
более64клеток по стороне отклоняется до обращения к графу. Все текущие
зарегистрированные native формы проходят сравнение с прежним алгоритмом.
Эта граница предотвращает новый бесконечный обход некорректного bbox.

`createCityLifeBlocker` читает три исходных membership index вместо создания
Set union. Они принадлежат одной завершённой physical preparation. Roads,
blocked и parking не меняются после подготовки; новая геометрия создаёт
другой owner, а существующие generation/revision/abort fences запрещают
публикацию старого результата. Исходные ссылки уже удерживались prepareLife,
поэтому их срок жизни не увеличивается. HTTP/MCP/SQL/PNG/стадии не меняются.

## Доказательства

Public RED→GREEN: прежний crew planner пытался перечислить индекс дорог;
новый planner работает при запрещённой итерации всех индексов с менее512
локальных обращений для контрольного участка. Второй RED — отсутствующий
membership-only life blocker. Frozen d315adf5 oracle сравнивает все native
формы, отрицательные координаты, разный порядок графа, занятость/дороги,
вход/fallback и лимиты0/1/2/3/6/12. Отдельно проверяются malformed bbox,
source alias/immutability и occupancy в реальном Pixi cinematic owner.

Связанный unit/integration набор:56проверок/10файлов, дополнительно6
transport/passenger walkway checks. В старом async life тесте исправлено
устаревшее полное ожидание: поле `context:SHOP` уже существовало в d315adf5.
Полный маршрут, parity с sync и неизменность входов проверяются по-прежнему.

Три отдельных Node24 процесса,507235 walking/321789 road cells: медиана
прежнего crew пути с копированием341,712мс, нового0,364мс. Все6путей имеют
одинаковый SHA. Это отдельная локальная фаза без стоимости загрузки города,
симуляции, эффектов и занятости движущихся жителей.

Три чередующиеся пары fresh Chromium/Metal на одном настоящем native10000
fixture576chunks: медиана mainheap послеGC478,488→469,641МиБ, экономия8,847МиБ.
Первый atomic frame5783→5200мс, полная физика22177→21188мс;5%regression guard
проходит. Это сопоставимые пары текущего окружения; сравнивать эти абсолютные
значения с прежними замерами при другой фоновой нагрузке нельзя.10000tasks,
576pages и завершённые worker pools0 проверены во всех6запусках.

Первоначальная оценка экономии16МиБ не подтвердилась: исходный paired gate
завершился FAILED и сохранён в evidence. Объекты/ключи клеток уже разделялись;
устраняется лишняя hash table ссылок. Прогноз исправлен на8МиБ в brief/task
v2 с явным read-back; те же неизменённые6запусков удовлетворяют этому порогу.
Исходный failed отчёт не перезапускался и не выдаётся за успешный. Цель256МиБ
этим срезом не достигнута.

Production build/typecheck/scoped lint проходят; fixed root AI-review —
без открытых замечаний в индексации, владении и совместимости.62 уникальные
unit/integration проверки в11файлах проходят.

6 scoped browser cases без retry:2desktop1440×1100,2Android Pixel7 и2iPhone13.
Настоящие MCP команды проходят все стадии, helicopter transfer и demolition;
отдельно проверены delayed artwork, rapid coalescing, rollback, map departure
и reduced motion. Старый полный cinematic тест растягивал также phone до
1440×1100; он исправлен на сохранение device viewport с явным guard<500px.
Полные mobile lifecycle cases повторены на компактных экранах. Остальной
успешный delayed-art case уже использовал compact viewport и переиспользован.
Снимки desktop и обоих компактных телефонов просмотрены; PNG и композиция
строителей не менялись. Визуальное ревью также зафиксировало чрезмерный
mobile stack уведомлений как отдельный следующий UX boundary.

Проверка200/1000/10000 на телефонах, транспортное оформление, иерархия новых
