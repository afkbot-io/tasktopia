# Tasktopia Hex Sprite Pack V1

Первый технически нормализованный набор для карты, показанной на референсе.

## Формат

- Сетка: `flat-top`, камера карты строго 90° сверху.
- Каждый тайл: прозрачный PNG `256 × 222`.
- Каждый объект: прозрачный PNG `320 × 384`, опорная точка `(160, 376)`.
- Полный гекс объекта расположен в прямоугольнике от `(32, 154)` до `(288, 376)`.
- Все пять стадий одного здания используют один размер и одну опорную точку, поэтому смена статуса не сдвигает объект.
- Рендерить с `image-rendering: pixelated` или nearest-neighbour filtering.

## Направления дорог

Используется шесть направлений: `NE`, `E`, `SE`, `SW`, `W`, `NW`. Полный список соединений каждого дорожного тайла находится в `manifest.json`.

Этот набор проверяет художественный и технический формат. Для полноценного автотайлинга понадобятся все 64 маски соединений дорог; недостающие варианты можно получать поворотом базовых PNG или отдельной генерацией.
