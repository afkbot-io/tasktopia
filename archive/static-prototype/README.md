# Архив статического прототипа

Здесь сохранён ранний браузерный vertical slice со сгенерированными PNG-кадрами и Python-утилитами. Он не входит в текущую сборку и оставлен только как визуальная история/исходный материал для будущего sprite pipeline.

Рабочая платформа находится в `src/` и запускается командами из корневого `README.md`.
