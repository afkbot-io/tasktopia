# Security Policy

## Поддерживаемая версия

Исправления безопасности выпускаются для актуального состояния ветки `main`.

## Сообщить об уязвимости

Не публикуйте рабочий exploit, токен, cookie, dump базы или персональные данные
в открытом issue. Используйте GitHub **Security → Report a vulnerability** в
репозитории Tasktopia и приложите:

- затронутую версию/commit;
- минимальные шаги воспроизведения;
- фактический и ожидаемый результат;
- оценку влияния;
- безопасный proof of concept без чужих данных.

До исправления не проверяйте уязвимость на чужих инсталляциях. Секреты MCP и
production credentials, случайно попавшие в сообщение, будут немедленно
отозваны.
