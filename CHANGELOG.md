# Changelog

## Unreleased

### Fixed

- Авторизация и регистрация теперь возвращают понятные русские сообщения вместо необработанного `Bad Request`.
- Повторная регистрация существующего email стабильно отвечает конфликтом `409`, включая конкурентные запросы.
- После успешного входа интерфейс дожидается загрузки страны; временный сбой загрузки показывается в форме и может быть повторён без нового входа.
- В районах новостроек автоматическая городская служба больше не снижает долю высоток и mixed-use корпусов ниже 70%.

### Added

- Read-only аудит всех 343 runtime PNG проверяет сетку 8 px, пять стадий, якоря, hard alpha, palette budget, геометрию машин и полноту manifest.
- Стресс-тест 10 городов закрепляет бюджеты генерации, материализации чанков и памяти.

### Changed

- Production deployment переведён на системный nginx перед Docker-приложением; Node-порт публикуется только на `127.0.0.1`.
- Production origin и отображаемый MCP endpoint используют `https://tasktopia.online`.

## 0.7.0

### Added

- Несколько стран на аккаунт, переключение активной страны и палата с приглашением зарегистрированных людей по email.
- Роли основателя и члена палаты; удаление страны и управление составом доступны только основателю.
- Редактирование имени аккаунта и персональный перевыпускаемый MCP-ключ.
- Создатель, ответственный и неизменяемая хроника событий задачи.
- Трёхуровневый веб-план: города, районы и задачи.
- MCP-команды `country.list`, `country.select` и `task.assign`.
- Пешеходные переходы как часть маршрута, уступающие машины, короткие безопасные связки разрывов тротуара и остановки людей у городских объектов.

### Changed

- В интерфейсе и публичном MCP используются только игровые названия: страны, города, районы и задачи.
- Персональный MCP-ключ работает с выбранной страной; перевыпуск отзывает прежний активный ключ аккаунта.
- Вертикальные машины перерисованы в симметричном формате `8×16`, получили корректное отражение и лёгкую анимацию подвески.
- Значения прогресса по умолчанию соответствуют пяти стадиям: `0 / 0 / 50 / 90 / 100`.

### Fixed

- Убрана лишняя серая кромка обычной дороги; специальные боковины сохранены только на мостах.
- Люди больше не прокладывают маршрут через footprint зданий и уличных объектов.
- Машины выбирают направление с учётом полосы и корректно отражаются при движении влево или вверх.

### Migration

- Существующая единственная страна каждого аккаунта автоматически становится первой страной владельца.
- Старые MCP-ключи получают владельца по стране. Данные городов, районов, задач и комментариев сохраняются.
