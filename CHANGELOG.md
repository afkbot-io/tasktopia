# Changelog

## 1.2.0

### Added

- Опубликована самодостаточная инструкция для ИИ по адресу `https://tasktopia.online/ai.md`: готовая конфигурация, модель сущностей, все 17 MCP tools, resources, scopes, ошибки и безопасный workflow.
- В настройках MCP появились отдельные действия для открытия и копирования публичной инструкции.

### Changed

- MCP переведён на официальные v2 server/client packages: основной протокол `2026-07-28` и stateless fallback для клиентов `2025-11-25` работают на одном Streamable HTTP endpoint. Web-standard Fetch handler подключён к Fastify через небольшой streaming bridge без несовместимых framework-adapter overrides.
- MCP принимает только `Authorization: Bearer ttp_mcp_...`, проверяет Origin для `GET`/`POST`/`DELETE` и возвращает стандартный Bearer challenge без credentials.
- Регистрационный workflow перенесён в `AppService.onboardUser`, чтобы создание пользователя, страны, session и первого города имело одну доменную транзакционную границу.
- Обновлены Fastify, PostgreSQL client, Zod, инструменты сборки и lint; TypeScript закреплён на последней версии, поддерживаемой текущим `typescript-eslint`.

### Fixed

- Удалены неиспользуемые стили прежних экранов авторизации, верхней панели, списка городов и старой панели стран; оставшиеся CSS selectors подтверждены реальными или динамическими компонентами.
- Мобильная кнопка районов больше не зависит от конфликтующих `hidden` и `inline-flex` utility-классов.
- Удалена ненужная Hono/Node-adapter цепочка с конфликтующим диапазоном версий; dependency audit проходит без overrides и известных runtime-уязвимостей.
- Генератор района пробует следующие безопасные road/endpoint пары, если ближайшая пара окружена reservation halo; regression seed `1901333332` закреплён тестом.

### Quality

- MCP smoke закрепляет modern/legacy negotiation, строгий Bearer, Origin, revocation, scopes и protected resources.
- Unit и Playwright проверяют полноту и публичную доступность `/ai.md`, а release QA вынесен в `docs/QA-1.2.md`.

## 1.1.2

### Fixed

- Production update script теперь повторяет health-запрос при `connection refused/reset` во время атомарной замены контейнера и не сообщает ложный провал успешного релиза.

## 1.1.1

### Performance

- WebSocket-клиент, план, карточка задачи, настройки и панель стран загружаются лениво и не входят в критический JS экрана входа.
- Стартовый JS уменьшен с `316 kB / 92.2 kB gzip` до `208 kB / 66.7 kB gzip`; карта остаётся отдельным lazy chunk.

## 1.1.0

### Added

- Регистрация получила обязательные в веб-интерфейсе названия первой страны и города; первый город создаётся сразу, без отдельного MCP-шага.
- Основатель может переименовать страну в переработанной панели управления проектом.
- На экране авторизации кратко показана модель Tasktopia: страна — проект, город — эпик/подпроект, район — спринт, здание — задача.

### Changed

- UI-слой переведён на Tailwind CSS 4 через официальный Vite plugin; прежние специализированные стили карты размещены в component layer и не добавляют runtime JavaScript.
- Верхняя панель разделена на контекст, показатели и действия, поэтому длинные названия больше не выталкивают кнопки и статусы.
- Панель стран и команды получила устойчивую desktop-сетку, полноэкранный mobile-режим, единые поля и кнопки, focus trap и возврат фокуса.

### Quality

- Onboarding пользователя, страны и города объединён одной PostgreSQL-транзакцией с безопасной поддержкой вложенных доменных операций.
- API и Playwright закрепляют создание первого города, role-based переименование, responsive 375/768/1440 и axe-аудит новых экранов.
- Deployment script и инструкция синхронизированы с production-каталогом `/srv/tasktopia/app`.

## 1.0.1

### Fixed

- Пустое состояние страны больше не накладывается на Suspense-loader карты; до появления первого города PixiJS-карта не загружается вовсе.
- Кнопка подключения MCP снова кликабельна, а текст, CTA и заголовок не пересекаются на desktop и mobile.

- Мобильная верхняя панель, формы разрешений и список ключей адаптированы для ширины 375 px без горизонтального overflow.

### Changed

- Профиль и MCP разделены по вкладкам; MCP-сценарий показывает endpoint, Streamable HTTP, Bearer-заголовок, копируемые параметры и последовательные шаги подключения.
- Неоднозначное «Перевыпустить» заменено на явные действия «Создать ключ» и «Заменить ключ», а копирование URL и секрета подтверждается в интерфейсе.

### Quality

- В Playwright добавлен axe-аудит serious/critical WCAG-нарушений, проверка focus trap/Escape и отсутствие overflow на 375/768/1440 px.

## 1.0.0

### Added

- Runtime и тестовый контур переведены с блокирующего SQLite на PostgreSQL 16 с асинхронным пулом, advisory-lock миграциями и checksum-защитой.
- Добавлен read-only SQLite → PostgreSQL importer с dry-run, batch-переносом, сбросом sequences и проверкой counts/constraints.
- Docker Compose и CI поднимают PostgreSQL с healthcheck; параллельные тестовые файлы используют изолированные схемы.

- Квартальный планировщик V9 с плотными группами новостроек `3×3`, улицами частных домов, коммерческими полосами и общими пешеходными связями.
- Метаданные группы, роли, ряда, фасадного семейства и общего доступа у участков; старые районы продолжают читаться без миграции.
- Детерминированные проверки автоматического заполнения квартала и малого мира из одного города, 10 районов и 20 задач.
- Релизный экран входа и явные состояния сессии: инициализация, анонимный доступ, активная сессия и восстанавливаемая ошибка.
- Обзорный LOD карты и пространственный `affectedBounds` в realtime-событиях для адресного обновления чанков.
- Лёгкий bootstrap, scoped plan endpoints и PostgreSQL-индекс принадлежности сущностей чанкам.
- Read-only роль наблюдателя, выбираемые MCP scopes и срок новых токенов 30/90/365 дней.
- Стабильная cursor pagination списка городов без изменения прежнего `/api/plan/cities`.

### Fixed

- Авторизация и регистрация теперь возвращают понятные русские сообщения вместо необработанного `Bad Request`.
- Повторная регистрация существующего email стабильно отвечает конфликтом `409`, включая конкурентные запросы.
- После успешного входа интерфейс дожидается загрузки страны; временный сбой загрузки показывается в форме и может быть повторён без нового входа.
- В районах новостроек автоматическая городская служба больше не снижает долю высоток и mixed-use корпусов ниже 70%.
- Парк сохраняет свой тротуарный якорь, поэтому поздняя задача не может занять единственный пешеходный выход.
- Городские участки магистрали переводятся в arterial и больше не разрезают кварталы highway-классом.
- Карта больше не пересоздаёт PixiJS canvas при обновлении bootstrap, а перемещение внутри прежнего диапазона не перестраивает неизменившиеся чанки.
- PixiJS-карта загружается отдельным lazy chunk: стартовый JS уменьшен примерно с 536 до 298 kB, а карта вынесена в chunk около 229 kB.
- Стартовый prefetch уменьшен с 0,75 до 0,25 viewport; overview получает разреженный terrain и лениво загружает только используемые PNG.
- CIVIC/COMMERCIAL кварталы используют свободные совместимые участки основной полосы до расширения, устраняя ложный отказ генерации на отдельных seed.
- Entity-слои PixiJS обновляются дифференциально по id/signature; неизменённые здания, районы, декор и features больше не пересоздаются при каждом сдвиге карты.
- Сервер повторно использует до 64 готовых chunk DTO через bounded LRU и адресно инвалидирует status-изменения.
- Chunk/bootstrap/plan JSON крупнее 1 KiB передаётся с Brotli/gzip-сжатием.
- CSRF-проверка больше не доверяет подставленному `X-Forwarded-Host`; session cookie использует `SameSite=Strict` и автоматически получает `Secure` в production.
- Logout отключает активные WebSocket-соединения пользователя, а отзыв членства — его соединения отозванной страны.
- Long-lived WebSocket раз в минуту повторно проверяет срок session и выбранную страну.
- Spatial membership теперь обновляется при изменении footprint/access task и feature, включая отрицательные координаты.
- MCP resources теперь подчиняются scopes; повреждённые, истёкшие и отозванные токены безопасно отклоняются.
- Spatial backfill разбит на возобновляемые batch-транзакции по 250 сущностей вместо одной долгой блокировки.
- Общая reconciliation-механика Pixi entity views вынесена из `WorldCanvas` и тестируется независимо.

### Quality

- Read-only аудит всех 343 runtime PNG проверяет сетку 8 px, пять стадий, якоря, hard alpha, palette budget, геометрию машин и полноту manifest.
- Все большие генераторные профили удалены; unit, scale и Playwright используют один город и 10 районов.
- World audit закрепляет максимум 20% asphalt для новых жилых районов.
- Asphalt audit учитывает дороги, asphalt-платформы, service pads и driveways, а не только строки дорожной таблицы.
- Добавлен coverage gate; текущий полный прогон покрывает 83,98% statements и 88,53% lines.
- Исправлена moderate-уязвимость транзитивного `hono`; dependency audit возвращает 0 известных уязвимостей.

### Changed

- Production deployment переведён на системный nginx перед Docker-приложением; Node-порт публикуется только на `127.0.0.1`.
- Production origin и отображаемый MCP endpoint используют `https://tasktopia.online`.
- Внутри района строится одна улица общего доступа; новые задачи заполняют существующую группу, а расширение добавляет целый квартал.
- Публичные тексты и снимки больше не используют маркировку демо/прототипа.

## 0.7.0

### Added

- Несколько стран на аккаунт, переключение активной страны и палата с приглашением зарегистрированных людей по email.
- Роли основателя и члена палаты; удаление страны и управление составом доступны только основателю.
- Редактирование имени аккаунта и персональный перевыпускаемый MCP-ключ.
- Создатель, ответственный и неизменяемая хроника событий задачи.
- Трёхуровневый веб-план: города, районы и задачи.
- MCP-команды `country.list`, `country.select` и `task.assign`.
- Пешеходные переходы как часть маршрута, уступающие машины, короткие безопасные связки разрывов тротуара и остановки людей у городских объектов.

### Changed

- В интерфейсе и публичном MCP используются только игровые названия: страны, города, районы и задачи.
- Персональный MCP-ключ работает с выбранной страной; перевыпуск отзывает прежний активный ключ аккаунта.
- Вертикальные машины перерисованы в симметричном формате `8×16`, получили корректное отражение и лёгкую анимацию подвески.
- Значения прогресса по умолчанию соответствуют пяти стадиям: `0 / 0 / 50 / 90 / 100`.

### Fixed

- Убрана лишняя серая кромка обычной дороги; специальные боковины сохранены только на мостах.
- Люди больше не прокладывают маршрут через footprint зданий и уличных объектов.
- Машины выбирают направление с учётом полосы и корректно отражаются при движении влево или вверх.

### Migration

- Существующая единственная страна каждого аккаунта автоматически становится первой страной владельца.
- Старые MCP-ключи получают владельца по стране. Данные городов, районов, задач и комментариев сохраняются.
