# Tasktopia

**Задачник, в котором работа команды превращается в живой пиксельный город.**

[Открыть Tasktopia](https://tasktopia.online) · [Подключить AI](docs/MCP.md) · [Установить на сервер](docs/DEPLOYMENT.md)

![Город Tasktopia](screenshots/dense-city-final/city-blocks.png)

Вы планируете задачи, строите продукт и принимаете результат. Город показывает этот путь: свободный участок становится стройкой, затем готовым зданием. За игровой картой остаются обычные инструменты команды — ответственные, сроки, зависимости, документы, чек-листы и история изменений.

## Как устроен мир

| В работе | В игре |
|---|---|
| Проект и его команда | Страна со своими участниками и правами |
| Направление или эпик | Город |
| Итерация или спринт | Район |
| Задача | Здание или общественное пространство |
| Ход работы | Стадии строительства |
| Долговременные знания проекта | Государственный архив |

На планете можно выбрать город и приблизиться к нему. В городе — рассмотреть здания и включить границы районов. Дороги, жители, транспорт и небольшие события оживляют карту; декоративные события не меняют задачи.

## Один рабочий день

1. **Найдите работу.** Откройте город и его район или найдите задачу по номеру и названию.
2. **Посмотрите очередь строительства.** В меню откройте «Документы → План строительства»: сначала работающие стройки, затем запланированные и завершённые. Выберите нужный район; нажатие на строку откроет карточку.
3. **Поручите работу агенту через MCP.** Создание задач, назначение, комментарии, чек-листы и изменение стадий выполняются через MCP. Интерфейс показывает результат и помогает ориентироваться. При начале неназначенной задачи ответственным становится авторизованный владелец токена.
4. **Примите результат.** Задача проходит планирование, начало работ, строительство, приёмку и завершение. На приёмке она ещё числится в работе.
5. **Сохраните знания.** Устойчивые правила и контекст проекта складывайте в архив; текущую работу оставляйте в задачах.

Можно отправить ссылку на задачу: карточка открывается сразу, без ожидания карты. Tasktopia устанавливается как PWA; уведомления подключаются по желанию. Фильтры города помогают найти свои объекты, приёмку, ремонт и просроченные работы.

## Команда и AI

Люди работают через интерфейс, AI-агенты — через MCP. Они видят те же задачи, документы, зависимости и историю. Для интеграции создайте отдельный токен с нужными правами в меню «Подключить MCP».

Каждый запрос MCP к проекту передаёт явный `countryId`. Изменяющие запросы используют `idempotencyKey`, чтобы безопасный повтор не создавал дубликаты.

## Запустить для разработки

Нужны **Node.js 24+**, npm, Git и Docker Compose v2 для PostgreSQL 16.

```bash
git clone https://github.com/afkbot-io/tasktopia.git
cd tasktopia
npm ci
cp .env.example .env
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d postgres
npm run seed
npm run dev
```

Откройте [localhost:5173](http://localhost:5173). Демонстрационные данные предназначены для локальной разработки. Параметры подключения и регистрации находятся в `.env`; не добавляйте секреты в Git.

Клиент построен на React, TypeScript и Vite, карта города — на PixiJS. Сервер использует Fastify и PostgreSQL; Redis подключается при необходимости.

## Установить для команды

Для установки с Docker:

```bash
git clone https://github.com/afkbot-io/tasktopia.git
cd tasktopia
cp deploy/.env.self-host.example .env
```

Задайте в `.env` собственный `POSTGRES_PASSWORD` (например, сгенерируйте его командой `openssl rand -hex 32`), затем:

```bash
docker compose up -d --build
docker compose ps
curl -fsS http://127.0.0.1:3000/health
docker compose exec app npm run user:create -- \
  --email admin@example.com \
  --name "Администратор" \
  --country "Компания" \
  --city "Главный продукт"
```

Команда создания пользователя скрыто запросит пароль. Войдите на [localhost:3000](http://localhost:3000) — первая страна и город уже будут готовы. В production публичная регистрация по умолчанию закрыта.

Настройка домена, HTTPS, резервных копий и обновлений описана в [руководстве по развёртыванию](docs/DEPLOYMENT.md).
