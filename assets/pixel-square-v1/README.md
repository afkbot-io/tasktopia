# Pixel Square V1

Прототип квадратной тайловой карты с камерой строго сверху.

- Сетка: `SQUARE_4_NEIGHBOUR`.
- Размер тайла: `192×192 px`.
- Порты: `N`, `E`, `S`, `W` в координате `96 px`.
- Дороги и реки имеют прямые и четыре поворотных варианта.
- Мост совмещает дорогу `W↔E` и реку `N↔S`.
- Все runtime-файлы находятся в `tiles/`.
- Контракты соединений и результаты проверки находятся в `manifest.json`.

Сборка:

```bash
python3 scripts/process-pixel-square-v1.py
```

Для автотайлинга достаточно кодировать каждую сторону четырьмя битами:

```text
N = 0001
E = 0010
S = 0100
W = 1000
```

Таким образом, все 16 комбинаций дороги или реки можно выбирать по одной маске соседей.
