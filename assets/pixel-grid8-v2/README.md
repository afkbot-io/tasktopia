# Pixel Grid 8 · V2

Расширение модульного пиксельного набора для сетки 8×8.

## Размеры

- `house-stage-1..5`: 32×24 px, footprint 4×3 клетки, anchor `(16, 24)`.
- `tree-*`, `streetlamp`, `utility-pole`: 8×16 px, footprint 1×1 клетка, anchor `(4, 16)`.
- `grass`, `road`, `curb`, `pavement`: 8×8 px.
- Перекрёстки, повороты и Т-соединения не являются спрайтами. Они собираются во время отрисовки из `road` и `curb` размером 8×8.

## Порядок отрисовки

1. Трава.
2. Асфальт.
3. Бордюр и дорожная разметка.
4. Площадка здания.
5. Здания и малые объекты, отсортированные по нижнему anchor.
6. Игровые подсветки и интерфейс.

У зданий и малых объектов прозрачный фон. Масштабировать только целым множителем с `nearest-neighbor`.

`manifest.json` содержит размеры, footprints, anchors и координаты кадров в атласе.
