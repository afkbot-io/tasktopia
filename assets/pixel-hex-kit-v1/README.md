# Pixel Hex Kit V1

Нативные runtime-спрайты без сглаживания. Все terrain PNG используют один и тот же `FLAT_TOP`-контур и побайтово одинаковую alpha mask.

- размер terrain: `96×83`;
- вершины: `(24,0) (71,0) (95,41) (71,82) (24,82) (0,41)`;
- смещение соседнего столбца: `71×41`;
- вертикальный шаг: `82`;
- соседние рёбра имеют абсолютно одинаковые конечные координаты;
- здание: `96×144`, anchor `(48,110)`, footprint `1` гекс;
- трава и платформа в building PNG отсутствуют;
- shadow хранится отдельным PNG.

Масштабировать спрайты можно только через `nearest-neighbour` на целое число: `2×`, `3×`, `4×`.

Пересборка:

```bash
python3 scripts/build-pixel-hex-kit.py
```
