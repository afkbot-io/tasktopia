# Инструкция по генерации спрайтов

## Неподвижные ограничения

- Любой runtime-размер кратен 8.
- Камера фронтальная/почти сверху, как в существующем наборе; без перспективного сокращения.
- Ограниченная палитра, тёмный сине-серый контур, жёсткие пиксельные кластеры.
- Никаких теней на фоне, градиентов, сглаживания, текста и логотипов.
- Canvas всех стадий одного здания одинаковый.
- Нижний центр и footprint не двигаются между стадиями.

## Исходный лист здания

Одно семейство генерируется одним изображением:

```text
[stage 1] [stage 2] [stage 3] [stage 4] [stage 5]
```

Требования к листу:

- ровно пять изолированных объектов;
- одна горизонтальная строка;
- каждый объект находится в своей равной пятой части canvas;
- одинаковая нижняя линия;
- одно здание, а не пять похожих зданий;
- однотонный chroma-фон `#ff00ff`;
- между объектами есть свободный фон.

## Постобработка

`scripts/process-pixel-city-pack-v3.py` выполняет:

1. деление исходника на пять равных колонок;
2. поиск alpha-bounds каждой стадии;
3. уменьшение до заранее заданного canvas;
4. ограничение палитры;
5. перевод alpha в жёсткие значения `0/255`;
6. bottom-center выравнивание;
7. сохранение пяти отдельных PNG;
8. упаковку в атлас и запись координат в manifest;
9. автоматическую проверку размеров и стадий.

Runtime не должен использовать chroma-исходники напрямую.

## Как добавить prop

1. Нарисовать один изолированный объект без тайла земли на chroma-фоне.
2. Выбрать canvas, кратный 8, и проверить читаемость на масштабе 1×.
3. Положить очищенный исходник в `source/props/<key>.png`.
4. Добавить одну `PropSpec`: key, label, runtime size и source.
5. Для согласованных ориентаций сохранить их равными сегментами одного листа и указать `segment_count/segment_index`.
6. Запустить сборщик; он сохранит пропорции, выровняет объект по нижнему центру, создаст runtime PNG и manifest entry.

Декор нельзя объединять с grass/pavement. Его logical footprint может быть меньше визуального canvas, но collision/placement должен задаваться данными карты отдельно.

## Как добавить здание

1. Выбрать ключ, категорию, canvas и footprint, кратные сетке.
2. Сгенерировать пятикадровый лист по шаблону из `PROMPTS.md`.
3. Удалить chroma-фон штатным helper-скриптом.
4. Положить исходник в `source/<group>/<key>.png`.
5. Добавить одну `BuildingSpec` в сборщик.
6. Запустить сборку.
7. Проверить контактный лист и сцену на конечном масштабе.

## Выбор canvas и footprint

Canvas описывает видимую картинку, footprint — землю. Они не обязаны совпадать по высоте.

Примеры:

- высотка `32×64`, footprint `4×3`;
- коттедж `16×24`, footprint `2×2`;
- магазин `48×16`, footprint `6×2`;
- школа `48×40`, footprint `6×5`.

Высокое здание растёт вверх от bottom-center anchor. Нельзя резервировать под него 8 клеток глубины только потому, что canvas имеет высоту 64 пикселя.

## Проверка качества

- силуэт читается при масштабе 1×;
- stage 3 явно является каркасом;
- stage 4 отличается от stage 5 строительными лесами;
- stage 1 и stage 2 сохраняют ширину будущего footprint;
- ни одна стадия не обрезана сверху или снизу;
- после chroma-removal нет пурпурного fringe;
- изображение не содержит полупрозрачных пикселей;
- prop не содержит встроенного terrain/surface и сохраняет исходные пропорции при нормализации;
- вертикальная и горизонтальная машины сохраняют одну модель и палитру, но рисуются отдельно под общий слегка наклонённый ракурс;
- горизонтальная проекция не должна совпадать с механическим поворотом вертикальной: в обеих читаются крыша, лобовое стекло и передняя часть.
