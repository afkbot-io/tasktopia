# Tasktopia Pixel Style V3

## Визуальный язык

- Геометрия: строгий `POINTY_TOP`, земля ортографически сверху.
- Здания: неглубокая 2.5D-проекция, в которой крыша важнее фасада.
- Пиксель: крупные осмысленные кластеры без сглаживания и фотореалистичного шума.
- Свет: всегда сверху-слева; тени и тёмные плоскости снизу-справа.
- Палитра: приглушённые olive/moss для земли, глубокий синий для воды, charcoal для дорог, тёплый кирпич и slate blue для архитектуры.
- Runtime-масштабирование: только целочисленный `nearest-neighbour`.

## Геометрический контракт

- terrain PNG: `167×193`;
- вершины: `(83,0) (166,48) (166,144) (83,192) (0,144) (0,48)`;
- соседние рёбра имеют одинаковые конечные координаты;
- каждый terrain-файл получает одну и ту же alpha mask;
- дороги и реки подключаются только через середины рёбер `NE/E/SE/SW/W/NW`, не через вершины;
- здание не содержит гекс, траву или платформу и ставится по anchor `(96,218)`.

## Пять стадий

1. Разметка и ограждение.
2. Фундамент.
3. Каркас и частичные стены.
4. Почти готовое здание с лесами.
5. Завершённое здание.

Стадии имеют одинаковую камеру, footprint, baseline и масштаб.
