# Pixel Top-down V1

Набор-прототип для карты с камерой строго сверху.

- Проекция: ортографическая, 90° сверху.
- Гекс: `POINTY_TOP`, `167×193 px`.
- Все тайлы используют одну и ту же альфа-маску.
- Соседние центры: `E/W = ±166 px`, диагональные направления = `±83/±144 px`.
- Runtime-файлы находятся в `tiles/`.
- Исходники с chroma-key и после удаления фона находятся в `source/`.
- Точная геометрия и тестовая сцена собираются скриптом `scripts/process-pixel-topdown-v1.py`.

Сборка:

```bash
python3 scripts/process-pixel-topdown-v1.py
```

Здание сейчас экспортировано как самостоятельный тайл с каменной площадкой поверх травяного основания. Следующий набор можно разделить на `terrain` и прозрачный `building overlay`, не меняя сетку.
