# Pixel Grid 8 V1

Минимальный модульный набор на базовой сетке `8×8 px`.

## Размеры

| Asset | Размер | Footprint |
|---|---:|---:|
| grass | `8×8` | `1×1` |
| road | `8×8` | `1×1` |
| curb | `8×8` | overlay `1×1` |
| shop-grocery | `32×16` | `4×2` |
| shop-bakery | `32×16` | `4×2` |

`curb.png` имеет прозрачный фон и накладывается поверх границы дороги. Магазины имеют прозрачный фон и якорь `[16, 16]` — центр нижней стороны спрайта.

`atlas.png` имеет фактический размер `64×32 px`. Preview-файлы увеличены только через nearest-neighbor.

Сборка:

```bash
python3 scripts/process-pixel-grid8-v1.py
```

При такой системе любые дальнейшие размеры должны быть кратны 8: `8`, `16`, `24`, `32`, `40`, `48` и так далее.
