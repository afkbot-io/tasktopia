# Tasktopia Generated Sprite Pack V2

Первый согласованный графический пакет для проверки визуального направления. Все runtime-файлы — прозрачные PNG `320×320`, рассчитанные на `POINTY_TOP`-гекс. Земля читается строго сверху, здания имеют умеренный псевдоизометрический объём, а собственная площадка здания всегда входит в тот же спрайт.

## Состав

- `environment`: 16 элементов — трава, луг, лес, камни, вода, три русла, пять дорожных конфигураций, мост, площадь и парк;
- `buildings`: 16 готовых построек — от коттеджа и магазина до полиции, пожарной части, клиники и школы;
- `stages`: 20 кадров — по пять стадий для коттеджа, многоквартирного дома, пожарной части и супермаркета;
- `source`: исходные AI-атласы с chroma key и очищенные исходники;
- `manifest.json`: размеры, пути, content bounds, ориентация гекса и направление света.

Всего: **52 runtime-спрайта**.

## Стадии задачи

| Статус задачи | Кадр | Визуальное состояние |
| --- | ---: | --- |
| `PLANNING` | 1 | пустая площадка, разметка и ограждение |
| `STARTED` | 2 | фундамент |
| `IN_PROGRESS` | 3 | несущий каркас |
| `TESTING` | 4 | почти готовое здание и леса |
| `COMPLETED` | 5 | готовое здание и благоустройство |

## Сборка и проверка

```bash
python3 scripts/process-generated-assets.py
python3 scripts/build-generated-scene.py
```

Первый скрипт режет исходные атласы, удаляет посторонние фрагменты соседних ячеек, проверяет непустую альфу и углы, затем пересобирает manifest. Второй собирает сцену и каталог исключительно из runtime PNG:

- `screenshots/generated-sprites-city-v2.png`;
- `screenshots/generated-sprite-catalog-v2.png`.

## Правила расширения

1. Камера, свет сверху-слева, палитра и точка привязки не меняются между наборами.
2. Для здания генерируется собственная платформа: двор, камень, асфальт, служебная площадка или парк.
3. Все пять стадий одного здания сохраняют одинаковый footprint, масштаб и положение платформы.
4. AI не определяет дорожную геометрию. Runtime выбирает соединения по 6-битной маске, а сгенерированный асфальт используется как материал; так исключаются кривые стыки.
5. Цвет района рисуется кодом только по внешнему периметру связной области. Цветные границы между соседними гексами запрещены.
6. Перед добавлением в runtime набор должен пройти contact-sheet review при масштабе 100%, 50% и игровом масштабе.
